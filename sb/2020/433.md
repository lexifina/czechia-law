# Vyhláška o údajích vedených v katalogu cloud computingu

433 *(účinnost od 2020-10-31)*

VYHLÁŠKA *(účinnost od 2020-10-31)*

ze dne 23. října 2020 *(účinnost od 2020-10-31)*

o údajích vedených v katalogu cloud computingu *(účinnost od 2020-10-31)*

Ministerstvo vnitra stanoví podle § 12 odst. 1 písm. g) zákona č. 365/2000 Sb., o informačních systémech veřejné správy a o změně některých dalších zákonů, ve znění zákona č. 12/2020 Sb.: *(účinnost od 2020-10-31)*

### § 1 *(účinnost od 2020-10-31)*

**Předmět úpravy** *(účinnost od 2020-10-31)*

Tato vyhláška stanoví údaje, které se vedou v katalogu cloud computingu o *(účinnost od 2020-10-31)*

a) poptávce cloud computingu, *(účinnost od 2020-10-31)*

b) nabídce cloud computingu, *(účinnost od 2020-10-31)*

c) cloud computingu využívaném orgány veřejné správy. *(účinnost od 2020-10-31)*

### § 2 *(účinnost od 2020-10-31)*

**Vymezení pojmů** *(účinnost od 2020-10-31)*

Pro účely této vyhlášky se rozumí *(účinnost od 2020-10-31)*

a) třídou cloud computingu cloud computing ve formě infrastruktury, cloud computing ve formě platformy a cloud computing ve formě aplikačního programového vybavení, *(účinnost od 2020-10-31)*

b) typem cloud computingu množina cloud computingů, které mají stejný účel, způsob plnění funkcionality cloud computingu a základní parametry, *(účinnost od 2020-10-31)*

c) oblastí cloud computingu skupina typů cloud computingů v rámci třídy cloud computingu, které plní obdobnou funkcionalitu cloud computingu, *(účinnost od 2020-10-31)*

d) základním parametrem cloud computingu údaj popisující objemové, výkonové, cenové nebo jiné vlastnosti cloud computingu, *(účinnost od 2020-10-31)*

e) bezpečnostní certifikací cloud computingu potvrzení, že cloud computing má vlastnosti vyžadované pro zařazení do příslušné bezpečnostní úrovně pro využívání cloud computingu orgány veřejné správy, požadované právním předpisem upravujícím kybernetickou bezpečnost, *(účinnost od 2020-10-31)*

f) bezpečnostní úrovní bezpečnostní úroveň podle právního předpisu upravujícího kybernetickou bezpečnost. *(účinnost od 2020-10-31)*

### § 3 *(účinnost od 2020-10-31)*

**Údaje vedené o poptávce cloud computingu** *(účinnost od 2020-10-31)*

V katalogu cloud computingu se o poptávce cloud computingu vedou *(účinnost od 2020-10-31)*

a) údaje identifikující poptávku cloud computingu, jimiž jsou *(účinnost od 2020-10-31)*

1\. název poptávaného cloud computingu, *(účinnost od 2020-10-31)*

2\. doba platnosti poptávky cloud computingu, *(účinnost od 2020-10-31)*

3\. doba předpokládaného využívání poptávaného cloud computingu, *(účinnost od 2020-10-31)*

b) údaje identifikující orgán veřejné správy, který cloud computing poptává, jimiž jsou *(účinnost od 2020-10-31)*

1\. název orgánu veřejné správy, *(účinnost od 2020-10-31)*

2\. identifikátor orgánu veřejné moci přidělený orgánu veřejné správy, *(účinnost od 2020-10-31)*

c) údaje charakterizující poptávaný cloud computing, jimiž jsou *(účinnost od 2020-10-31)*

1\. třída poptávaného cloud computingu, *(účinnost od 2020-10-31)*

2\. oblast poptávaného cloud computingu, *(účinnost od 2020-10-31)*

3\. typ poptávaného cloud computingu, *(účinnost od 2020-10-31)*

4\. základní parametry poptávaného cloud computingu, *(účinnost od 2020-10-31)*

5\. bezpečnostní úroveň poptávaného cloud computingu, *(účinnost od 2020-10-31)*

6\. bezpečnostní certifikace poptávaného cloud computingu. *(účinnost od 2020-10-31)*

### § 4 *(účinnost od 2020-10-31)*

**Údaje vedené o nabídce cloud computingu** *(účinnost od 2020-10-31)*

V katalogu cloud computingu se o nabídce cloud computingu vedou *(účinnost od 2020-10-31)*

a) údaje identifikující nabídku cloud computingu, jimiž jsou *(účinnost od 2020-10-31)*

1\. název nabízeného cloud computingu, *(účinnost od 2020-10-31)*

2\. identifikační údaj poptávky cloud computingu, na který nabídka cloud computingu reaguje, *(účinnost od 2020-10-31)*

3\. doba platnosti nabídky cloud computingu, *(účinnost od 2020-10-31)*

b) údaje identifikující poskytovatele cloud computingu, který cloud computing nabízí, jimiž jsou *(účinnost od 2020-10-31)*

1\. u právnické osoby obchodní firma nebo název, identifikační číslo osoby nebo obdobné číslo přidělované v zahraničí a její sídlo, je-li v zahraničí, *(účinnost od 2020-10-31)*

2\. u podnikající fyzické osoby obchodní firma nebo jméno, popřípadě jména, a příjmení, včetně odlišujícího dodatku nebo dalšího označení, identifikační číslo osoby nebo obdobné číslo přidělované v zahraničí a její sídlo, je-li v zahraničí, *(účinnost od 2020-10-31)*

c) údaje charakterizující nabízený cloud computing, jimiž jsou *(účinnost od 2020-10-31)*

1\. třída nabízeného cloud computingu, *(účinnost od 2020-10-31)*

2\. oblast nabízeného cloud computingu, *(účinnost od 2020-10-31)*

3\. typ nabízeného cloud computingu, *(účinnost od 2020-10-31)*

4\. název konkrétního cloud computingu, který odpovídá nabízenému typu cloud computingu, *(účinnost od 2020-10-31)*

5\. základní parametry nabízeného cloud computingu, *(účinnost od 2020-10-31)*

6\. bezpečnostní úroveň nabízeného cloud computingu, *(účinnost od 2020-10-31)*

7\. bezpečnostní certifikace nabízeného cloud computingu, *(účinnost od 2020-10-31)*

8\. údaj o předpokládaném místu zpracování informací orgánu veřejné správy a předpokládané době, předpokládaném rozsahu a předpokládaném účelu zpracování informací orgánu veřejné správy v tomto místě. *(účinnost od 2020-10-31)*

### § 5 *(účinnost od 2020-10-31)*

**Údaje vedené o cloud computingu využívaném orgány veřejné správy** *(účinnost od 2020-10-31)*

V katalogu cloud computingu se o cloud computingu využívaném orgány veřejné správy vedou *(účinnost od 2020-10-31)*

a) údaje identifikující využívaný cloud computing, jimiž jsou *(účinnost od 2020-10-31)*

1\. název využívaného cloud computingu, *(účinnost od 2020-10-31)*

2\. datum zahájení využívání cloud computingu, *(účinnost od 2020-10-31)*

3\. datum předpokládaného ukončení využívání cloud computingu, *(účinnost od 2020-10-31)*

b) údaje identifikující orgán veřejné správy, který cloud computing využívá, jimiž jsou *(účinnost od 2020-10-31)*

1\. název orgánu veřejné správy, *(účinnost od 2020-10-31)*

2\. identifikátor orgánu veřejné moci přidělený orgánu veřejné správy, *(účinnost od 2020-10-31)*

c) údaje identifikující poskytovatele cloud computingu, který využívaný cloud computing poskytuje, jimiž jsou *(účinnost od 2020-10-31)*

1\. u právnické osoby obchodní firma nebo název, identifikační číslo osoby nebo obdobné číslo přidělované v zahraničí a její sídlo, je-li v zahraničí, *(účinnost od 2020-10-31)*

2\. u podnikající fyzické osoby obchodní firma nebo jméno, popřípadě jména, a příjmení, včetně odlišujícího dodatku nebo dalšího označení, identifikační číslo osoby nebo obdobné číslo přidělované v zahraničí a její sídlo, je-li v zahraničí, *(účinnost od 2020-10-31)*

d) údaje charakterizující využívaný cloud computing, jimiž jsou *(účinnost od 2020-10-31)*

1\. třída využívaného cloud computingu, *(účinnost od 2020-10-31)*

2\. oblast využívaného cloud computingu, *(účinnost od 2020-10-31)*

3\. typ využívaného cloud computingu, *(účinnost od 2020-10-31)*

4\. bezpečnostní úroveň využívaného cloud computingu, *(účinnost od 2020-10-31)*

5\. identifikační číslo smlouvy o poskytování využívaného cloud computingu uzavřené mezi orgánem veřejné správy a poskytovatelem cloud computingu přidělené správcem registru smluv, eviduje-li se smlouva v registru smluv, *(účinnost od 2020-10-31)*

6\. identifikátor informačního systému veřejné správy, pro který cloud computing slouží. *(účinnost od 2020-10-31)*
