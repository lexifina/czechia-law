# Usnesení předsednictva České národní rady o vyhlášení dodatečných voleb do zastupitelstev v obcích

USNESENÍ

předsednictva České národní rady

ze dne 22. prosince 1990

o vyhlášení dodatečných voleb do zastupitelstev v obcích

Předsednictvo České národní rady vyhlašuje podle § 47 zákona ČNR č. 368/1990 Sb., o volbách do zastupitelstev v obcích, dodatečné volby do obecních zastupitelstev v obcích:

| Liteň | okres Beroun |
|---|---|
| Dřetovice, Přelic, Třebusice | Kladno |
| Doubravčice | Kolín |
| Bášť, Babice | Praha-východ |
| Nedrahovice | Příbram |
| Zbytiny | Prachatice |
| Hlohovice, Kladruby | Rokycany |
| Hrobce, Lhotka nad Labem | Litoměřice |
| Blšany | Louny |
| Volevčice | Most |
| Kunvald | Ústí n. Orlicí |
| Bukovice, Brusná, Hluboké Dvory, Zhoř | Blansko |
| Zálesná Zhoř | Brno-venkov |
| Machová | Zlín |
| Branišov, Hlávkov, Jiřín | Jihlava |
| Ocmanice, Cidlina | Třebíč |
| Blahoňov, Prosetín, Skorotice, Křížovice | Žďár nad Sázavou |
| Lipina | Opava |
| Lužná | Vsetín |
| Kamenná | Šumperk |

a stanoví den jejich konání na sobotu 26. ledna 1991 s tím, že zákonné lhůty mohou být přiměřeně zkráceny.
