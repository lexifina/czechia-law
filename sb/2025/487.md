# Vyhláška o stanovení kódů typů výdajů na volební kampaň

487

VYHLÁŠKA

ze dne 20. listopadu 2025

o stanovení kódů typů výdajů na volební kampaň

Úřad pro dohled nad hospodařením politických stran a politických hnutí stanoví podle § 10 odst. 3 zákona č. 234/2025 Sb., o volebních kampaních a o transparentnosti a cílení politické reklamy:

### § 1

**Kódy typů výdajů na volební kampaň**

Jednotlivé typy výdajů na volební kampaň označí kandidující volební strana ve zprávě o financování volební kampaně kódy, které jsou uvedeny v příloze k této vyhlášce.

### § 2

**Účinnost**

Tato vyhláška nabývá účinnosti dnem 1. ledna 2026.

Předseda:

Ing. Sivera v. r.

## Příloha

**Kódy typů výdajů na volební kampaň**

| Kód | Popis |
|---|---|
| A - Tištěná reklama a propagace |
| A1 | Inzerce a propagační články v tisku |
| A2 | Letáky a volební noviny - návrh, tisk a distribuce |
| B - Venkovní reklama a propagace |
| B1 | Pronájem reklamních ploch - billboard, bigboard, citylight |
| B2 | Pronájem reklamních ploch - vozidla veřejné dopravy |
| B3 | Pronájem reklamních ploch - další plochy |
| B4 | Výroba, tisk nosičů pro reklamní plochy mimo letáky a volební noviny |
| C - Služby propagace na sociálních sítích a internetu |
| C1 | Správa a tvorba textů na sociálních sítích |
| C2 | Placené nástroje na sociálních sítích |
| C3 | Správa a tvorba textů na internetu mimo sociální sítě, včetně vlastního webu |
| C4 | Reklama a propagační články na internetu mimo sociální sítě |
| D - Zboží a služby v kontaktní kampani |
| D1 | Propagační předměty, zboží a občerstvení |
| D2 | Technické zajištění akcí |
| D3 | Personální zajištění akcí |
| D4 | Nájem prostor a prostranství, včetně poplatků za zábor veřejného prostranství |
| D5 | Pronájem, leasing, zápůjčka dopravních prostředků |
| D6 | Pohonné hmoty, ubytování a jiné cestovní náklady |
| E - Další služby |
| E1 | Marketing a propagace |
| E2 | Softwarové a datové služby |
| E3 | Výroba propagačních materiálů |
| F - Ostatní |
| F1 | Mzdové náklady na volební kampaň |
| F2 | Běžný spotřební materiál pro kampaň |
| F3 | Ostatní výdaje nezařaditelné pod jiný kód - vyžaduje se slovní upřesnění |
