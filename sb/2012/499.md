# Usnesení Poslanecké sněmovny k zákonu, kterým se mění zákon č. 44/1988 Sb., o ochraně a využití nerostného bohatství (horní zákon), ve znění pozdějších předpisů, přijatému Parlamentem dne 4. listopadu 2012 a vrácenému prezidentem republiky dne 19. listopadu 2012

499

USNESENÍ

Poslanecké sněmovny

ze dne 19. prosince 2012

Poslanecká sněmovna setrvává na zákonu, kterým se mění zákon č. 44/1988 Sb., o ochraně a využití nerostného bohatství (horní zákon), ve znění pozdějších předpisů, přijatém Parlamentem dne 4. listopadu 2012 a vráceném prezidentem republiky dne 19. listopadu 2012.

Němcová v. r.
