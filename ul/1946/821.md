# Vyhláška č. 1 f/45 Svazu pro dobytek, maso a ryby, kterou se mění a doplňuje tržní řád jatečného dobytka.

821\.

Vyhláška č. 1 f/45

Svazu pro dobytek, maso a ryby

ze dne 22. března 1946,

kterou se mění a doplňuje tržní řád jatečného dobytka.

Svaz pro dobytek, maso a ryby, v dalším „Svaz“, pověřen ministrem výživy podle § 6 dekretu presidenta republiky ze dne 27. října 1945, č. 118 Sb., o opatřeních v řízení vyživovacího hospodářství, vyhlašuje se souhlasem ministerstva zdravotnictví a nejvyššího úřadu cenového:

## I.

Vyhlášky Svazu č. 1/45 o tržním řádu jatečného dobytka ze dne 21. března 1945 (Ú. l. č. 74/45, běž. č. 141), ve znění vyhlášek ji měnících a doplňujících, jest používati i nadále s těmito změnami:

1\. § 103, odst. 2 zní:

„(2) Výdej a odběr se musí díti v plné výši váhy, na kterou znějí odběrní doklady.

| Z tohoto ustanovení platí tyto výjimky: |
|---|
| a) | ve dvojnásobném množství: |
| Z hovězího: |
|  | mozek, |
|  | srdce. |
| Z vepřů: |
|  | hlava bez laloku, |
|  | mozek, |
|  | srdce, |
|  | kolena. |
| Z telat: |
|  | mozek, |
|  | srdce, |
|  | kolena. |
| Masné výrobky: |
|  | játrový salám, |
|  | játrová paštika v krabicích, |
| b) | ve čtyřnárobném množství: |
| Z hovězího: |
|  | hlavy bez jazyků, |
|  | oháňka, |
|  | plíce, |
|  | slezina, |
|  | drštky opařené, solené, včetně čepce a slezu. |
| Z vepřů: |
|  | ocásky, |
|  | plíce, |
|  | slezina. |
| Z telat: |
|  | plíce, |
|  | slezina. |
| Ze skopového: |
|  | všechny části drobů a hlavy s mozkem a jazykem a bez jazyku. |
| Masné výrobky: |
|  | jaternice obyčejné, |
|  | jelita obyčejná, |
|  | krevní tlačenka. |

c) Bez započítání na odběrní doklady se smějí vydávati:

Všechny výše neuvedené části vnitřností, všechny kosti z hovězího masa, tlamy, vemena, šlachy, kůže z hlav, maso z jícnu, ořez z kostí, hovězí nohy a knihy (část hovězího žaludku), z vepřového nožičky, ouška, ořez z kostí a jícny, rypáčky a kůže, z telat okruží, hlavy bez mozku a jazyku, ořez z kostí, telecí nožky a telecí žaludky, dále skopové drštičky a krev všeho druhu a z masných výrobků aspik, huspenina a salát z volské tlamy.

d) Masné konservy se započítávají v plné výši čisté váhy obsahu, smíšené konservy ve výši obsahu masa.

e) Uzené maso s vrostlými kostmi a zaschlý trvanlivý salám se vydává na odběrní doklady v množství o 10% menším, uzené maso bez kostí o 20% a vařená šunka bez kostí v množství o 25% menším, než na které znějí odběrní doklady."

2\. V § 173, odst. 2 ruší se věta:

„č. 5 o zákazu vývozu masných výrobků z některých míst (Ú. l. č. 71/1944)“.

3\. Příloha č. 11 „Nejnižší požadavky pro výrobu koňských masných výrobků“ se doplňuje dalším odstavcem tohoto znění:

Pro dobu přechodnou jest však u koňských masných výrobků, uvedených v této příloze pod čís. 1, 2, 3, 5 a 6, používati jako moučnou přísadu (mlýnské výrobky) výhradně jen mouku sojovou, a to ve výši 7%.

## II.

Účinnost vyhlášky Svazu č. 5 o zákazu vývozu masných výrobků z některých míst (Ú. l. č. 71/1944) se ruší.

## III.

Tato vyhláška nabývá účinnosti dnem 29. dubna 1946.

Svaz pro dobytek, maso a ryby.

Dr. Václav Novák v. r.
