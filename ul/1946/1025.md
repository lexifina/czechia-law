# Vyhláška nejvyššího úřadu cenového, kterou se mění a doplňuje vyhláška nejvyššího úřadu cenového o cenách a prodejních podmínkách přírodního lihového kvasného octa.

1025\.

Vyhláška

nejvyššího úřadu cenového

ze dne 9. dubna 1946,

kterou se mění a doplňuje vyhláška nejvyššího úřadu cenového o cenách a prodejních podmínkách přírodního lihového kvasného octa.

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto:

### Článek I.

Vyhláška nejvyššího úřadu cenového ze dne 2. února 1946, běž. č. 395, o cenách a prodejních podmínkách přírodního lihového kvasného octa (Ú. l. I. č. 23/1946) se mění a doplňuje takto:

1\. § 1, odst. 2 zní:

„(2) Při prodeji v lahvích za 1 litr:

| a) | 4% konsumního | 4.15 Kčs, |
|---|---|---|
|  | 8% konsumního | 7.20 Kčs, |
|  | 4% jakostního | 4.65 Kčs, |
|  | 8% jakostního | 8.20 Kčs; |
| b) | při odběru alespoň 200 lahví octa najednou: |
|  | 4% konsumního | 4.10 Kčs, |
|  | 8% konsumního | 7.15 Kčs, |
|  | 4% jakostního | 4.60 Kčs, |
|  | 8% jakostního | 8.15 Kč.“ |

2\. § 3 zní:

### „§ 3.

**Nejvyšší spotřebitelské ceny.**

Při prodeji spotřebiteli v drobném smějí být za přírodní lihový kvasný ocet požadovány nejvýše tyto ceny:

| a) | za 1 litr volného zboží: |  |
|---|---|---|
|  | 4% konsumního | 4.— Kčs, |
|  | 8% konsumního | 7.60 Kčs, |
|  | 4% jakostního | 4.50 Kčs, |
|  | 8% jakostního | 8.80 Kčs; |
| b) | za 1 litr lahvového zboží: |
|  | 4% konsumního | 5.10 Kčs, |
|  | 8% konsumního | 8.80 Kčs, |
|  | 4% jakostního | 5.70 Kčs, |
|  | 8% jakostního | 10.— Kčs. |

Za půjčenou láhev může být požadována záloha 4 Kčs za kus."

### Článek II.

Tato vyhláška nabývá účinnosti dnem 15. dubna 1946.

Za předsedu nejvyššího úřadu cenového:

Dr. Maur v. r.
