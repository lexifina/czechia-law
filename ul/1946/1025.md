# Vyhláška nejvyššího úřadu cenového, kterou se mění a doplňuje vyhláška nejvyššího úřadu cenového o cenách a prodejních podmínkách přírodního lihového kvasného octa.

1025\. *(účinnost od 1946-04-15)*

Vyhláška *(účinnost od 1946-04-15)*

nejvyššího úřadu cenového *(účinnost od 1946-04-15)*

ze dne 9. dubna 1946, *(účinnost od 1946-04-15)*

kterou se mění a doplňuje vyhláška nejvyššího úřadu cenového o cenách a prodejních podmínkách přírodního lihového kvasného octa. *(účinnost od 1946-04-15)*

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto: *(účinnost od 1946-04-15)*

### Článek I. *(účinnost od 1946-04-15)*

Vyhláška nejvyššího úřadu cenového ze dne 2. února 1946, běž. č. 395, o cenách a prodejních podmínkách přírodního lihového kvasného octa (Ú. l. I. č. 23/1946) se mění a doplňuje takto: *(účinnost od 1946-04-15)*

1\. § 1, odst. 2 zní: *(účinnost od 1946-04-15)*

„(2) Při prodeji v lahvích za 1 litr: *(účinnost od 1946-04-15)*

| a) | 4% konsumního | 4.15 Kčs, |
|---|---|---|
|  | 8% konsumního | 7.20 Kčs, |
|  | 4% jakostního | 4.65 Kčs, |
|  | 8% jakostního | 8.20 Kčs; |
| b) | při odběru alespoň 200 lahví octa najednou: |
|  | 4% konsumního | 4.10 Kčs, |
|  | 8% konsumního | 7.15 Kčs, |
|  | 4% jakostního | 4.60 Kčs, |
|  | 8% jakostního | 8.15 Kč.“ | *(účinnost od 1946-04-15)*

2\. § 3 zní: *(účinnost od 1946-04-15)*

### „§ 3. *(účinnost od 1946-04-15)*

**Nejvyšší spotřebitelské ceny.** *(účinnost od 1946-04-15)*

Při prodeji spotřebiteli v drobném smějí být za přírodní lihový kvasný ocet požadovány nejvýše tyto ceny: *(účinnost od 1946-04-15)*

| a) | za 1 litr volného zboží: |  |
|---|---|---|
|  | 4% konsumního | 4.— Kčs, |
|  | 8% konsumního | 7.60 Kčs, |
|  | 4% jakostního | 4.50 Kčs, |
|  | 8% jakostního | 8.80 Kčs; |
| b) | za 1 litr lahvového zboží: |
|  | 4% konsumního | 5.10 Kčs, |
|  | 8% konsumního | 8.80 Kčs, |
|  | 4% jakostního | 5.70 Kčs, |
|  | 8% jakostního | 10.— Kčs. | *(účinnost od 1946-04-15)*

Za půjčenou láhev může být požadována záloha 4 Kčs za kus." *(účinnost od 1946-04-15)*

### Článek II. *(účinnost od 1946-04-15)*

Tato vyhláška nabývá účinnosti dnem 15. dubna 1946. *(účinnost od 1946-04-15)*

Za předsedu nejvyššího úřadu cenového: *(účinnost od 1946-04-15)*

Dr. Maur v. r. *(účinnost od 1946-04-15)*
