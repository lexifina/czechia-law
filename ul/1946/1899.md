# Vyhláška ministra průmyslu, kterou se zrušuje použivatelnost příkazů ministra hospodářství a práce v oboru elektrotechniky.

1899\.

Vyhláška

ministra průmyslu

ze dne 8. října 1946,

kterou se zrušuje použivatelnost příkazů ministra hospodářství a práce v oboru elektrotechniky.

Podle § 3 dekretu presidenta republiky ze dne 27. října 1945, č. 109 Sb., o řízení výroby, ustanovuji:

### § 1.

Dnem účinnosti této vyhlášky se zrušuje použivatelnost těchto příkazů ministra hospodářství a práce:

| Kr. E-38 | ze dne 9. června 1948, č. j. W-I/Sc-179.720/43, |
|---|---|
| o zákazu výroby elektrických ukazovatelů směru, |
| Kr. E-66 | ze dne 4. března 1944 |
| o omezení počtu typů částí a soustav traťového vedení u elektrických dráhových zařízení, |
| Kr. E-89 | ze dne 28. srpna 1944 |
| o výrobě, provedení a objednávání transformátorů, |
| Kr. E-94 | ze dne 28. července 1944 |
| o zmenšení počtu typů součástí traťových vedení elektrických dráhových zařízení, |
| Kr. E-96 | ze dne 11. srpna 1944 |
| o omezení stavu zakázek elektrotechnických výrobků, |
| Kr. E-111 | ze dne 21. října 1944, |
| kterým se mění příkaz Kr. E-96 ministra hospodářství a práce ze dne 11. srpna 1944 o omezení stavu zakázek elektrotechnických výrobků, |
| E-1 | ze dne 13. července 1943. č. j. W-I/3c-IV/12/c-425.277/42, |
| o výrobě elektrotechnického materiálu a spotřebičů pro domácnost, |
| E-2a | ze dne 18. prosince 1942, č. j. W-I/3c-621.219/42, |
| o elektroakustických sdělovacích přístrojích, |
| E-4 | ze dne 8. prosince 1942, č. i. W-l.3c/IV/12c-619.098/42, |
| o výrobě rozhlasových přijímačů a sériové výrobě jejich součástí, |
| E-7 | ze dne 8. března 1943, č. j. W-I/3c-614.632/42, |
| o omezení typů ve výrobě elektrických vozíků. |

### § 2.

Tato vyhláška nabývá účinnosti dnem vyhlášení.

Ministr průmyslu:

B. Laušman v. r.
