# Vyhláška československého monopolu lihového o prodejních cenách lihu.

1829\. *(účinnost od 1946-10-07)*

Vyhláška *(účinnost od 1946-10-07)*

československého monopolu lihového *(účinnost od 1946-10-07)*

ze dne 25. září 1946 *(účinnost od 1946-10-07)*

o prodejních cenách lihu. *(účinnost od 1946-10-07)*

Československý monopol lihový stanoví podle § 98 zákona ze dne 19. února 1946, č. 30 Sb., se souhlasem nejvyššího úřadu cenového prodejní ceny lihu takto: *(účinnost od 1946-10-07)*

### § 1. *(účinnost od 1946-10-07)*

Plná prodejní cena čistého lihu k výrobě lihovin, trestí, léčiv, voňavek a pod.: *(účinnost od 1946-10-07)*

|  | Maloprodej: |  |  |
|---|---|---|---|
| 1 l prostor. |  | Kčs 186.— | za prostorový litr 95 obj. % z dodacího místa |
| přes 1 l do 5 l prostor. |  | Kčs 182.50 |
| přes 5 l do 10 l prostor. |  | Kčs 180.— |
| přes 10 l do 25 l prostor. |  | Kčs 179.— |
| od 25 l do 50 l alkoholu |  | Kčs 182.— | za litr alkoholu z dodacího o místa. |
| přes 50 l do 100 l alkoholu |  | Kčs 180.— |
| přes 100 l do 150 l alkoholu |  | Kčs 179 50 |
| přes 150 l do 280 l alkoholu |  | Kčs 179.— |
|  | Velkoprodej: |  | za litr alkoholu vyplaceně do stanice příjemce. |
| přes 280 l alkoholu |  | Kčs 175.— |
| Přirážka za bezvodý líh, pokud se dodává k shora uvedeným účelům, Kčs 0.50 za litr alkoholu. | *(účinnost od 1946-10-07)*

### § 2. *(účinnost od 1946-10-07)*

Prodejní cena čistého lihu k výrobě octa: *(účinnost od 1946-10-07)*

|  | Maloprodej: |  |  |
|---|---|---|---|
| přes 25 l do 100 l alkoholu |  | Kčs 13.90 | za litr alkoholu z dodacího místa. |
| přes 100 l do 280 l alkoholu |  | Kčs 13.70 |
|  | Velkoprodej: |  |  |
| přes 280 l alkoholu |  | Kčs 13.— | za litr alkoholu vyplaceně do stanice příjemce. | *(účinnost od 1946-10-07)*

Surový líh, pokud se k výrobě octa dodává, účtuje se o Kčs 0.20 za litr alkoholu levněji. *(účinnost od 1946-10-07)*

### § 3. *(účinnost od 1946-10-07)*

Prodejní cena lihu k čištění, topení, vaření, osvětlování, k účelům živnostenským nebo vědeckým, úplně nebo neúplně denaturovaného, k neúplné denaturaci nebo nedenaturovaného: *(účinnost od 1946-10-07)*

|  | Maloprodej: |  |  |
|---|---|---|---|
| do 25 l prostor. |  | Kčs 8.20 | za prostor. litr 95 obj. % z dodacího místa |
| přes 25 l do 100 l alkoholu |  | Kčs 8.40 | za litr alkoholu z dodacího místa. |
| přes 100 l do 280 l alkoholu |  | Kčs 8.20 |
|  | Velkoprodej: |  |  |
| přes 280 l alkoholu |  | Kčs 7.50 | za litr alkoholu vyplaceně do stanice příjemce. |
| Zvláštní cena lihu k pálení pro rozdělovače (velkoobchodníky) úplně denaturovaného lihu: |
| přes 280 l alkoholu |  | Kčs 7.25 | za litr alkoholu vyplaceně do stanice příjemce. |
| cena, za kterou rozdělovač (velkoobchodník) do dodává líh k pálení maloobchodníkům | Kčs 7.60 | za prostorový litr 95 obj. % (= Kčs 8.— za litr alkoholu) franko dům, |
| cena, za kterou maloobchodník prodává líh k pálení spotřebitelům | Kčs 8.50 | za prostorový litr 95 obj. %. | *(účinnost od 1946-10-07)*

Přirážka za bezvodý líh, pokud se dodává ke shora uvedeným účelům, Kčs 0.50 za litr alkoholu. *(účinnost od 1946-10-07)*

### § 4. *(účinnost od 1946-10-07)*

Prodejní cena bezvodého lihu k míšení s pohonnými látkami u oprávněných odběratelů: *(účinnost od 1946-10-07)*

|  | Maloprodej: |  |  |
|---|---|---|---|
| přes 25 l do 100 l alkoholu |  | Kčs8.40 | za litr alkoholu z dodacího místa. |
| přes 100 l do 280 l alkoholu |  | Kčs8.20 |
|  | Velkoprodej: |  |  |
| přes 280 l v sudech |  | Kčs7.75 | za litr alkoholu vyplaceně do stanice příjemce. |
| v jímkách nejméně 100 hl |  | Kčs7.50 | *(účinnost od 1946-10-07)*

### § 5. *(účinnost od 1946-10-07)*

1\. Tato vyhláška platí pro celé území Československé republiky a nabývá účinnosti dne 7. října 1916. *(účinnost od 1946-10-07)*

2\. Týmž dnem pozbývá platnosti vyhláška ministra financí ze dne 24. září 1945 o prodejních cenách lihu v zemích českých (Ú. l. I, částka 107, běž. č. 275) a vyhláška pověřence financí ze dne 16. března 1946, Úr. vest. č. 22, běž. č. 849, kterou se stanoví prodejní ceny lihu na Slovensku. *(účinnost od 1946-10-07)*

Československý monopol lihový: *(účinnost od 1946-10-07)*

Ing. J. Šála *(účinnost od 1946-10-07)*

za ústředního ředitele čs. monopolu lihového. *(účinnost od 1946-10-07)*
