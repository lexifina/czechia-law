# Vyhláška nejvyššího úřadu cenového, kterou se mění vyhláška nejvyššího úřadu cenového o cenách jatečného dobytka všeho druhu, masa, vnitřností (drobů), loje, sádla, jatečných koní, koňského masa a masa v nuceném výseku.

1083\.

Vyhláška

nejvyššího úřadu cenového

ze dne 19. dubna 1946,

kterou se mění vyhláška nejvyššího úřadu cenového o cenách jatečného dobytka všeho druhu, masa, vnitřností (drobů), loje, sádla, jatečných koní, koňského masa a masa v nuceném výseku.

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto:

### Článek I.

Ustanovení § 31 vyhlášky nejvyššího úřadu cenového ze dne 3. prosince 1945, běž. č. 472, o cenách jatečného dobytka všeho druhu, masa, vnitřností (drobů), loje, sádla, jatečných koní, koňského masa a masa v nuceném výseku (Ú. l. I. č. 146/1945) se mění a bude zníti takto:

|  | § 31. | Kčs |
|---|---|---|
|  | 1. Syrové sádlo (plst a hřbetní s kůží) nejvyšší spotřebitelská cena v balení | 52.— |
|  | 2. Škvařené sádlo: |  |
| A. | nejvyšší spotřebitelská cena v balení | 69.— |
| B. | nejvyšší přejímací cena Společnosti od řezníka, loco sběrna Společnosti | 65.— |
| C. | pevná přejímací cena Společnosti od samozásobitele |  |
|  | a) loco sběrna Společnosti | 58.— |
|  | b) z obce samozásobitele mimo sídlo sběrny | 56.— |
| D. | nejvyšší nákupní cena malorozdělovače loco sběrna Společnosti | 63.— |
|  | 3. Uzená slanina: |  |
|  | Nejvyšší spotřebitelská cena v balení: |  |
|  | a) v místech s trhy na jatečný dobytek | 58.— |
|  | b) v ostatních místech | 56.— |
|  | 4. Solená slanina: |  |
| A. | nejvyšší spotřebitelská cena v balení | 52.— |
| B. | nejvyšší nákupní cena malorozdělovače loco sběrna, v balení | 46.— |

5\. Řezník prodávající sádlo je povinen odvésti prostřednictvím obvodové sběrny sádla a loje Svazu pro mléko a tuky na úhradu výdajů spojených s opracováním, skladováním a distribucí sádla vyrovnávací částku

| a) | v Praze | Kčs 2.— |
|---|---|---|
| b) | v místech s trhy na jatečný dobytek | Kčs 2.60 |
| c) | v ostatních místech | Kčs 4.— |

6\. Odměny sběrnám sádla a loje stanoví nejvyšší úřad cenový zvláštním výměrem a Svaz pro mléko a tuky vydá k tomu prováděcí předpisy.

7\. Rozdíl mezi přejímací cenou škvařeného sádla převzatého od řezníků a nákupní cenou maloobchodu uhradí sběrnám Svaz pro mléko a tuky.

8\. Ceny sádla a slaniny se rozumějí i s daní z obratu.

### Článek II.

Tato vyhláška nabývá účinnosti dnem 29. dubna 1946.

Za předsedu nejvyššího úřadu cenového:

Dr. Maur v. r.
