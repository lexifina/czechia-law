# Vyhláška nejvyššího úřadu cenového, kterou se mění vyhláška o nejvyšších cenách zdejších surových kozlečin, kozin, kozlovic, skopovic, jehnětin, divočin, jemných ročků, ročků, suchých vepřovic a psích koží.

2139\.

Vyhláška

nejvyššího úřadu cenového

ze dne 6. prosince 1946,

kterou se mění vyhláška o nejvyšších cenách zdejších surových kozlečin, kozin, kozlovic, skopovic, jehnětin, divočin, jemných ročků, ročků, suchých vepřovic a psích koží.

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto:

### Čl. I.

Vyhláška nejvyššího úřadu cenového ze dne 18. června 1946, o nejvyšších cenách zdejších surových kozlečin, kozin, kozlovic, skopovic, jehnětin, divočin, jemných ročků, ročků, suchých vepřovic a psích koží (Ú. l. I č. 110/1946, běž. č. 1452), se mění takto:

Ustanovení § 1, odst. 8, písm., c) až e) zní:

|  |  | Při prodeji |  |
|---|---|---|---|
|  |  | výrobcem (chovatelem, lovcem) | velkonákupnou zpracovatelům |
|  | Druh: | mokré | sušené | sušené |
|  |  | za 1 kus Kčs |
| c) | srnčiny červené letní | 17.50 | 35.— | 50.— |
|  | krátkosrsté podzimní | 11.50 | 23.— | 33.— |
|  | dlouhosrsté zimní | 8.— | 16.— | 22.— |
|  | Tyto ceny se snižují u kožek poškozených nejméně o polovici, u výmětu nejméně o tři čtvrtiny. |  |  |  |
| d) | Kožky muflonové nepoškozené. | 23.— | 46.— | 65.— |
|  | U kožek nepoškozených platí tyto nejmenší srážky: za vadu v odpadu Kčs 2.— za kus, za vadu v jádru Kčs 4.— za kus, za vadu v jádru a odpadu Kčs 4.— za kus. |  |  |  |
| e) | škáry z černé zvěře nepoškozené a poškozené | 10.50 | 21.— | 30.— |
|  | ze selat a výmět. | 5.50 | 11.— | 16.— |
|  | Poškozené kůže složené zvěře spárkaté jsou jen kůže s nejvýše 2 otvory po střele, jejichž každý průměr převyšuje 3 cm. |  |  |  |

### Čl. II.

Tato vyhláška nabývá účinnosti 1. dnem po vyhlášení.
