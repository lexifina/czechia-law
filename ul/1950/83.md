# Vyhláška ministerstev vnitřního obchodu a průmyslu, kterou se mění a doplňuje příloha vyhlášky o úpravě dodávek a odběru drogistického zboží a fotopotřeb.

83\.

VYHLÁŠKA

ministerstev vnitřního obchodu a průmyslu

ze dne 27. ledna 1950,

kterou se mění a doplňuje příloha vyhlášky o úpravě dodávek a odběru drogistického zboží a fotopotřeb.

Ministerstva vnitřního obchodu a průmyslu stanoví podle §§ 1 a 2 zákona č. 160/1949 Sb., o vnitřním obchodě, a podle §§ 1 až 3 dekretu presidenta republiky č. 109/1945 Sb., o řízení výroby:

### § 1.

Seznam zboží, jenž tvoří přílohu 1 vyhlášky ministerstev vnitřního obchodu a průmyslu č. 1089/1949 Ú. l. I, o úpravě dodávek a odběru drogistického zboží a fotopotřeb, se doplňuje takto:

|  | 06 44 | výrobky pyrotechnické (prskavky a pod.) |
|---|---|---|
| ex | 17 16 9 | pilníčky na nehty |
|  | 17 85 2 | kadeřnické potřeby (natáčky, vlniče, spony a pod.) |
| ex | 17 90 0 | kovové hřebeny, rtěnky a pod., mimo postříbřené, pozlacené a ve spojení s drahými kovy |
|  | 22 64 0 | hřebeny |
| ex | 22 64 9 | pohárky bakelitové, pouzdra bakelitová pro osobní potřebu, spony do vlasů celuloidové a z umělých hmot |
| ex | 22 76 0 | kartáče s výjimkou technických a průmyslových |
|  | 3 | štětky mimo technické |
|  | 4 | košťata |
|  | 9 | ostatní kartáčnické výrobky mimo technické |
|  | 25 54 0 | síťky na vlasy pánské a dámské z příze a z lidských vlasů |
|  | 28 63 4 | mycí houby pro domácnost. |

### § 2.

Tato vyhláška nabývá účinnosti dnem vyhlášení.

Kliment v. r.

Ministr vnitřního obchodu:

Krajčír v. r.
