# Vyhláška ministerstev vnitřního obchodu a průmyslu, kterou se mění a doplňuje příloha vyhlášky č. 1184/1919 Ú. l. I, o úpravě dodávek a odběru dopravních prostředků, loveckých zbraní a šicích strojů.

179\.

VYHLÁŠKA

ministerstev vnitřního obchodu a průmyslu

ze dne 5. března 1950,

kterou se mění a doplňuje příloha vyhlášky č. 1184/1949 Ú. l. I, o úpravě dodávek a odběru dopravních prostředků, loveckých zbraní a šicích strojů.

Ministerstva vnitřního obchodu a průmyslu stanoví podle §§ 1 a 2 zákona č. 160/1949 Sb., o vnitřním obchodě a podle §§ 1 až 3 dekretu č. 109/1945 Sb., o řízení výroby:

### § 1.

Seznam zboží, jenž tvoří přílohu č. 1 vyhlášky ministerstev vnitřního obchodu a průmyslu č. 1184/1949 Ú. l. I, o úpravě dodávek a odběru dopravních prostředků, loveckých zbraní a šicích strojů, se mění a doplňuje takto:

Položky:

| ex | 12 | 92 | 9 | kompresory k huštění pneumatik pro autoservice |
|---|---|---|---|---|
|  | 17 | 72 |  | automobilové kování |
|  | 17 | 72 | 1 | kliky a kličky |
|  | 17 | 72 | 2 | zámky |
| ex | 17 | 90 | 7 | lovecké odznaky a ozdobné předměty |
|  | 18 | 25 | 3 | usměrňovače lankové jen pro nabíjení autobaterií sériově vyráběné |
|  | 18 | 25 | 9 | vývojky k lampovým usměrňovačům k pol. 18 25 3 |
|  | 19 | 73 | 3 | zadní světla trojúhelníky |
|  | 19 | 73 | 8 | reflektory pomocné |
| ex | 23 | 63 |  | papírové zátky a uzávěrky pro lovce |
|  | 27 | 22 |  | lovecké potřeby jako lovecký prach, papírové zátky a uzávěrky |
|  | 27 | 22 | 3 | pouzdra na zbraně |

se nahrazují položkami:

| ex | 12 | 92 | 1 | kompresory k huštění pneumatik pro autoservice |
|---|---|---|---|---|
|  | 17 | 72 |  | automobilové kování (i zámky) |
| ex | 17 | 90 | 5 | lovecké odznaky |
| ex | 17 | 90 | 7 | lovecké ozdobné předměty |
|  | 18 | 25 | 3 | usměrňovače lampové jen pro nabíjení autobaterií sériově vyráběné |
|  | 18 | 25 | 9 | výbojky k lampovým usměrňovačům k pol. 18 25 3 |
| ex | 19 | 73 | 3 | návěstní světla pro motorová vozidla a jízdní kola |
| ex | 19 | 73 | 8 | zvláštní svítidla pro motorová vozidla a jízdní kola |
| ex | 23 | 63 |  | papírové zátky a uzávěrky pro lovecké náboje |
| ex | 27 | 22 | 3 | pouzdra na zbraně, lovecké dalekohledy a puškové zaměřovače |
|  | 27 | 22 | 5 | lovecké potřeby. |

### § 2.

Tato vyhláška nabývá účinnosti dnem vyhlášení.

Kliment v. r.
