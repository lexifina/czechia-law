# Vyhláška ministerstev vnitřního obchodu a průmyslu, kterou se mění příloha vyhlášky o úpravě dodávek a odběru drogistického zboží a fotopotřeb.

321\.

VYHLÁŠKA

ministerstev vnitřního obchodu a průmyslu

ze dne 20. dubna 1950,

kterou se mění příloha vyhlášky o úpravě dodávek a odběru drogistického zboží a fotopotřeb.

Ministerstva vnitřního obchodu a průmyslu stanoví podle §§ 1 a 2 zákona č. 160/1949 Sb., o vnitřním obchodě, a podle §§ 1 až 3 dekretu presidenta republiky č. 109/1945 Sb., o řízení výroby:

### § 1.

Seznam zboží, jenž tvoří přílohu 1 vyhlášky ministerstev vnitřního obchodu a průmyslu č. 1089/1949 Ú. l. I, o úpravě dodávek a odběru drogistického zboží a fotopotřeb, ve znění vyhlášky č. 83/1950 Ú. l. I se mění takto:

Vypouštějí se položky:

|  | 06 | 72 | 2 | prostředky proti škůdcům uskladněného obilí |
|---|---|---|---|---|
|  |  |  | 32 | prostředky otravné proti žravým škůdcům fluoridové |
| ex |  |  | 39 | prostředky otravné proti žravým škůdcům jiné mimo Morkit |
|  |  |  | 73 | prostředky dotykové kombinované |
| ex |  |  | 79 | prostředky dotykové jiné s obsahem DDT. |

### § 2.

Tato vyhláška nabývá účinnosti dnem 22. dubna 1950.

Ministr průmyslu:

Kliment v. r.

Ministr vnitřního obchodu:

Krajčír v. r.
