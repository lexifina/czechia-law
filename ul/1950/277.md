# Vyhláška ministerstva vnitřního obchodu o cenách technických benzinů.

277\. *(účinnost od 1950-05-01)*

VYHLÁŠKA *(účinnost od 1950-05-01)*

ministerstva vnitřního obchodu *(účinnost od 1950-05-01)*

ze dne 26. dubna 1950 *(účinnost od 1950-05-01)*

o cenách technických benzinů. *(účinnost od 1950-05-01)*

Ministerstvo vnitřního obchodu stanoví v dohodě se státním úřadem plánovacím podle § 2 odst. 2, § 5 odst. 1 a § 7 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen: *(účinnost od 1950-05-01)*

### § 1. *(účinnost od 1950-05-01)*

(1) Spotřebitelské ceny technických benzinů činí bez všeobecné daně při odběru do 20 kg nejvýše: *(účinnost od 1950-05-01)*

|---|---|---|
|  | lékárenský benzin |  |
|  | gasolin |  |
|  | petroléther |  |
|  | analytický benzin | Kčs 17,80 |
| b) | Benzin pro důlní lampy | Kčs 17,40 |
| c) | Benziny extrakční |  |
|  | s destilační křivkou |  |
|  | 65°—85° C |  |
|  | 50°—110° C |  |
|  | 80°—110° C | Kčs 16,50 |
| d) | Benziny rozpouštěcí |  |
|  | s destilační křivkou |  |

| g) | Benziny jiné jakosti | Kčs 17,80 |
|  | (jiné destilační křivky) |  | *(účinnost od 1950-05-01)*

(2) S cen uvedených v odstavci 1 poskytují se podnikům veřejného zpracovatelského sektoru (podniky národní, komunální, družstevní a podniky pod národní správou těchto podniků) při odběru najednou pro jejich vlastní spotřebu tyto slevy: *(účinnost od 1950-05-01)*

| při odběru | za každý kg |
|---|---|

| 1—5 sudů | Kčs 3,— |
| přes 5 sudů | Kčs 3,30 |
| v cisterně dodavatelově (nejméně 10.000 kg) | Kčs 4,60 | *(účinnost od 1950-05-01)*

### § 2. *(účinnost od 1950-05-01)*

Ceny technických benzinů uvedené v § 1 se rozumějí při dodávce *(účinnost od 1950-05-01)*

a) v celých cisternách vyplaceně do nejbližší železniční stanice odběratele, *(účinnost od 1950-05-01)*

b) v sudech nebo plechovkách ze skladu dodavatele, *(účinnost od 1950-05-01)*

za hotové beze srážky při placení do 14 dnů ode dne odeslání faktury, po případě na dobírku. Faktura nesmí být odeslána před vyskladněním zboží. *(účinnost od 1950-05-01)*

### § 3. *(účinnost od 1950-05-01)*

(1) Při dodávce technických benzinů spotřebiteli v litrech činí cena Kčs 22,— za 1 litr. *(účinnost od 1950-05-01)*

(2) Při dodávce technických benzinů spotřebiteli v množství menším než 1 litr činí spotřebitelská cena Kčs 3,— za každou 0,1 litru. *(účinnost od 1950-05-01)*

(3) Ceny uvedené v odstavcích 1 a 2 se rozumějí včetně všeobecné nákupní daně. *(účinnost od 1950-05-01)*

### § 4. *(účinnost od 1950-05-01)*

Ministerstvo vnitřního obchodu může v dohodě se státním úřadem plánovacím povolit nebo nařídit výjimky z ustanovení této vyhlášky. *(účinnost od 1950-05-01)*

### § 5. *(účinnost od 1950-05-01)*

Přestupky ustanovení této vyhlášky se trestají podle § 11 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen. *(účinnost od 1950-05-01)*

### § 6. *(účinnost od 1950-05-01)*

Vyhláška nejvyššího úřadu cenového č. 306/1947 Ú. l. I, o cenách technických benzinů, se zrušuje. *(účinnost od 1950-05-01)*

### § 7. *(účinnost od 1950-05-01)*

Tato vyhláška nabývá účinnosti dnem 1. května 1950. *(účinnost od 1950-05-01)*
