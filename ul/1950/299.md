# Vyhláška Ústřední národní pojišťovny o změně obvodů okresních národních pojišťoven.

299\.

VYHLÁŠKA

Ústřední národní pojišťovny

ze dne 31. března 1950

o změně obvodů okresních národních pojišťoven.

Ústřední národní pojišťovna stanoví se souhlasem ministerstva práce a sociální péče podle § 174 odst. 1 zákona č. 99/1948 Sb., o národním pojištění toto:

### § 1.

Zrušuje se okresní národní pojišťovna v Říčanech; obvod působnosti okresní národní pojišťovny v Praze se rozšiřuje na okres Říčany.

### § 2.

Zrušuje se okresní národní pojišťovna v Moravských Budějovicích; obvod působnosti okresní národní pojišťovny v Třebíči se rozšiřuje na okres Moravské Budějovice.

### § 3.

Touto vyhláškou se mění příloha vyhlášky Ústřední národní pojišťovny č. 679/1949 Ú. l. I takto:

| čís. běž.: | čís. kat.: | sídlo ONP: | obvod tvoří okresy: |
|---|---|---|---|
| 1 | 0101 | Praha | území města Prahy, Praha-jih, |
|  |  |  | Praha-sever, Praha-východ, |
|  |  |  | Praha-západ, Říčany |
| 17 | 0123 | se škrtá |  |
| 91 | 0907 | se škrtá |  |
| 93 | 0910 | Třebíč | Třebíč, Mor. Budějovice, Velké Meziříčí. |

### § 4.

Tato vyhláška nabývá účinnosti dnem 1. dubna 1950.
