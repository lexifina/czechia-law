# Vyhláška ministra zahraničního obchodu o vyloučení některých druhů zboží z výhradního oprávnění akciové společnosti Kovo.

310\.

VYHLÁŠKA

ministra zahraničního obchodu

ze dne 12. května 1950

o vyloučení některých druhů zboží z výhradního oprávnění akciové společnosti Kovo.

Podle § 2 odst. 3 zákona č. 119/1948 Sb., o státní organisaci zahraničního obchodu a mezinárodního zasilatelství, ustanovuji:

### § 1.

Ke dni 15. května 1950 vylučuje se dovoz a vývoz dále uvedeného zboží z výhradního oprávnění Kovo, akciové společnosti pro obchod s kovodělnými a strojírenskými výrobky a surovinami.

Z přílohy I vyhlášky ministra zahraničního obchodu č. 3271/1948 Ú. l. I se proto vypouštějí tyto druhy zboží:

| Poř. čís. stat. seznamu zboží | Pojmenování zboží: |
|---|---|
|  | (vydání 1950): |
|  | 1545/4 (dříve 1672) | Motory výbušné a spalovací k letadlům. |
| ex 1545/5 (dříve ex 1673) | Součásti motorů poř. čís. 1545/4. |
|  | 1669/1—3 (dříve 1669/1—2) 1670 | Letadla všeho druhu. |
|  | Hotové součástky k letadlům. |

### § 2.

Tato vyhláška nabývá účinnosti dnem vyhlášení.

Za ministra:

Jonáš v. r.
