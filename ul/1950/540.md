# Vyhláška ministerstva zemědělství o výkupních cenách pozdních bramborů ze sklizně 1950.

540\. *(účinnost od 1950-09-11)*

VYHLÁŠKA *(účinnost od 1950-09-11)*

ministerstva zemědělství *(účinnost od 1950-09-11)*

ze dne 8. září 1950 *(účinnost od 1950-09-11)*

o výkupních cenách pozdních bramborů ze sklizně 1950. *(účinnost od 1950-09-11)*

Ministerstvo zemědělství stanoví na základě usnesení vlády ze dne 4. dubna 1950 podle § 2 odst. 2 a §§ 5 a 7 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen: *(účinnost od 1950-09-11)*

### § 1. *(účinnost od 1950-09-11)*

(1) Pevné výkupní ceny za 100 kg bramborů činí: *(účinnost od 1950-09-11)*

| a) | brambory jedlé |  |  |
|---|---|---|---|
|  | standard | I. |  | Kčs | 160,—, |
|  | II. |  | Kčs | 130,—, |
|  | III. |  | Kčs | 105,—, |
|  | VI. |  | Kčs | 95,—, |
| b) | brambory krmné | Kčs | 95,—, |
| c) | brambory průmyslové |  |  |
|  | (pro průmyslové zpracování) | Kčs | 95,—. | *(účinnost od 1950-09-11)*

Za každých celých 0,10 kg škrobu nad 16% v čisté váze brambor uvedených pod písm. c) přísluší k těmto cenám příplatek 0,50 Kčs. *(účinnost od 1950-09-11)*

(2) Ceny podle odstavce 1 platí za čistou váhu, franko vagon (bez záhražek) nejbližší nakládací železniční stanice pěstitele nebo franko jiné místo určení, pokud je toto místo bližší než uvedená nakládací stanice, bez obalu (pytlů a pod.). *(účinnost od 1950-09-11)*

### § 2. *(účinnost od 1950-09-11)*

Přestupky ustanovení této vyhlášky se trestají podle § 89 trestního zákona správního. *(účinnost od 1950-09-11)*

### § 3. *(účinnost od 1950-09-11)*

Tato vyhláška nabývá účinnosti dnem 11. září 1950. *(účinnost od 1950-09-11)*
