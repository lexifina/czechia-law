# Vyhláška ministerstva zemědělství o výkupních cenách pozdních bramborů ze sklizně 1950.

540\.

VYHLÁŠKA

ministerstva zemědělství

ze dne 8. září 1950

o výkupních cenách pozdních bramborů ze sklizně 1950.

Ministerstvo zemědělství stanoví na základě usnesení vlády ze dne 4. dubna 1950 podle § 2 odst. 2 a §§ 5 a 7 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen:

### § 1.

(1) Pevné výkupní ceny za 100 kg bramborů činí:

| a) | brambory jedlé |  |  |
|---|---|---|---|
|  | standard | I. |  | Kčs | 160,—, |
|  | II. |  | Kčs | 130,—, |
|  | III. |  | Kčs | 105,—, |
|  | VI. |  | Kčs | 95,—, |
| b) | brambory krmné | Kčs | 95,—, |
| c) | brambory průmyslové |  |  |
|  | (pro průmyslové zpracování) | Kčs | 95,—. |

Za každých celých 0,10 kg škrobu nad 16% v čisté váze brambor uvedených pod písm. c) přísluší k těmto cenám příplatek 0,50 Kčs.

(2) Ceny podle odstavce 1 platí za čistou váhu, franko vagon (bez záhražek) nejbližší nakládací železniční stanice pěstitele nebo franko jiné místo určení, pokud je toto místo bližší než uvedená nakládací stanice, bez obalu (pytlů a pod.).

(3) Stanovené pevné výkupní ceny bramborů v odstavci 1 se zvyšují o dobové příplatky při dodávce:

|  |  | v době | v době |
|---|---|---|---|
| a) | brambory jedlé | od 22. ledna 1951 | od 26. února 1951 |
|  | standart I | Kčs 4.— | Kčs 13.— |
|  | standart II | Kčs 4.— | Kčs 13.— |
|  | standart III | Kčs 4.— | Kčs 13.— |
|  | standart IV | Kčs 4.— | Kčs 13.— |
| b) | brambory krmné | Kčs 4.— | Kčs 13.— |
| c) | brambory průmyslové (pro průmyslové zpracování) | Kčs 5.— | Kčs 5.—. |

### § 2.

Přestupky ustanovení této vyhlášky se trestají podle § 89 trestního zákona správního.

### § 3.

Tato vyhláška nabývá účinnosti dnem 11. září 1950.
