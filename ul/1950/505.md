# Vyhláška ministerstev financí, práce a sociální péče a státního úřadu plánovacího, kterou se vydávají předpisy o náhradách za používání vlastních osobních motorových vozidel při pracovních cestách a vnějším řízení.

505\.

VYHLÁŠKA

ministerstev financí, práce a sociální péče a státního úřadu plánovacího

ze dne 5. srpna 1950,

kterou se vydávají předpisy o náhradách za používání vlastních osobních motorových vozidel při pracovních cestách a vnějším řízení.

Ministerstva financí, práce a sociální péče a státní úřad plánovací stanoví v dohodě s ostatními zúčastněnými ústředními úřady a s jednotnou odborovou organisací podle § 10 odst. 1 zákona č. 234/1949 Sb., o náhradách cestovních, stěhovacích a jiných výdajů:

### § 1.

**Osobní rozsah platnosti.**

Tato vyhláška platí pro

a) zaměstnance s výjimkou vojenských osob v činné službě, příslušníků Sboru národní bezpečnosti a příslušníků Sboru vězeňské stráže,

b) jiné osoby s výjimkou veřejných funkcionářů.

### § 2.

**Náhrady.**

(1) Vlastníkům příslušejí, za používání jejich osobních motorových vozidel (dále jen „vozidla“) při pracovních cestách a vnějším řízení náhrady podle této vyhlášky, vysloví-li zaměstnavatel nebo příslušný činitel (dále jen „zaměstnavatel“) s použitím vozidla souhlas.

(2) V náhradách jsou zahrnuty náklady na amortisaci, na zúročení částky vynaložené na zakoupení vozidla, na udržování a opravy vozidla a pneumatik, na spotřebované pohonné látky a mazadla, na garážování (kromě případů uvedených v § 3 odst. 4), na ochranu proti mrazu, na veškeré pojištění a všechny ostatní provozní a udržovací náklady.

(3) Nekryje-li pojištění proti následkům zákonné odpovědnosti z provozu vozidla nároky osob dopravovaných a není-li sjednáno pojištění vozidla proti poškození a ztrátě, ani pojištění úrazové, musí se vlastník zavázat písemným vlastnoručně podepsaným prohlášením, že poškození, ztráta vozidla, úrazy a nehody, které by ho nebo jím přepravované osoby při použití vozidla stihly, jdou na jeho vlastní nebezpečí.

### § 3.

**Výše náhrady.**

(1) Náhrada za jeden kilometr jízdy činí:

|  |  | Kčs |
|---|---|---|
| a) | u osobních aut s obsahem válců |  |
|  | do 500 kubických centimetrů (ccm) | 2.90 |
|  | nad 500 ccm do 600 ccm | 3.80 |
|  | nad 600 ccm do 750 ccm | 4.10 |
|  | nad 750 ccm do 900 ccm | 4.50 |
|  | nad 900 ccm do 1000 ccm | 4.70 |
|  | nad 1000 ccm do 1100 ccm | 5.— |
|  | nad 1100 ccm do 1200 ccm | 5.20 |
|  | nad 1200 ccm do 1300 ccm | 5.70 |
|  | nad 1300 ccm do 1400 ccm | 6.10 |
|  | nad 1400 ccm do 1500 ccm | 6.60 |
|  | nad 1500 ccm | 6.90 |
| b) | u motorových kol a motocyklů (motocyklů s přívěsným vozíkem) s obsahem válců |  |
|  | do 125 ccm | 2.— |
|  | nad 125 ccm do 175 ccm | 2.10 |
|  | nad 175 ccm do 250 ccm | 2.40 |
|  | nad 250 ccm do 350 ccm | 2.60 |
|  | nad 350 ccm do 500 ccm | 2.80 |
|  | nad 500 ccm do 750 ccm | 3.10 |
|  | nad 750 cm | 3.50. |

(2) Náhrada přísluší vlastníku za celkový počet kilometrů ujetých prokázané vozidlem při pracovních cestách nebo, při vnějším řízení. Jízda musí být vykonána nejkratší cestou sjízdnou pro použité vozidlo. Začaté kilometry se zaokrouhlují nahoru na celé kilometry.

(3) V případech, kdy povaha práce sama způsobuje, že se pracovní místo mění, nebo kde jde o vnější pracovní výkony, které patří k pravidelným pracovním úkolům toho, kdo je koná, je možno stanovití, pokud se týče sjednati, paušální počet kilometrů pro výpočet náhrady.

(4) Je-li vlastník při používání vozidla nucen uschovat vozidlo při jízdách mimo bydliště v garáži nebo na jiném místě za úplatu, přísluší mu náhrada těchto prokázaných výdajů zvlášť ve výši odpovídající cenovým předpisům.

### § 4.

**Příplatky při přepravě dalších osob a zavazadel.**

(1) Přepravuje-li vlastník pro zaměstnavatele zároveň jiné osoby, přísluší mu mimo náhradu podle § 3 za každý ujetý kilometr příplatek Kčs 0.30 za každou přepravovanou osobu.

(2) Přepravuje-li vlastník v zájmu zaměstnavatele zároveň zavazadla nebo náklady o váze nad 10 kg, přísluší mu za celou vzdálenost ujetou se zavazadlem nebo nákladem za každých i započatých 25 kg váhy příplatek Kčs 3.—.

### § 5.

**Obdobné použití ustanovení vyhlášky.**

Ustanovení této vyhlášky platí obdobně i pro případy, kdy se při pracovní cestě nebo vnějším řízení použije vozidla, které nepatří osobě uplatňující nárok na náhradu ani zaměstnavateli.

### § 6.

**Účinnost.**

Tato vyhláška nabývá účinnosti dnem 1. srpna 1950.
