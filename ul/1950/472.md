# Vyhláška ministerstva vnitřního obchodu o úplatách za půjčení obalů při dodávkách lihu a přiboudliny a o vracení těchto obalů.

472\.

VYHLÁŠKA

ministerstva vnitřního obchodu

ze dne 26. července 1950.

o úplatách za půjčení obalů při dodávkách lihu a přiboudliny a o vracení těchto obalů.

Ministerstvo vnitřního obchodu stanoví v dohodě se státním úřadem plánovacím podle § 2 odst. 2 a § 5 odst. 1 a § 7 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen:

### § 1.

Ustanovení této vyhlášky se vztahují na tyto druhy obalů:

a) železniční kotlové vozy (cisterny),

b) kovové a dřevěné sudy,

c) plechové konve,

d) skleněné láhve (balony a demijony) a jiné,

které slouží k přepravě všech druhů lihu a přiboudliny.

### § 2.

(1) Příjemci dodávek lihu a přiboudliny jsou povinni vraceti půjčené obaly ihned po vyprázdnění v řádném stavu a to — pokud nebylo s dodavatelem písemně sjednáno nic jiného — v těchto lhůtách:

a) železniční kotlové vozy (cisterny) nejpozději následující všední den po dni přistavení drahou,

| b) ostatní obaly nejpozději | do 30 dnů, |
|---|---|

jež se počítají při dodávkách po železnici ode dne odevzdání zboží železnici k přepravě, při ostatních dodávkách ode dne převzetí zboží ze skladu dodávajícího místa.

(2) Při vracení obalů drahou je stanovená lhůta dodržena, byl-li před jejím uplynutím vyprázdněný obal odevzdán železnici k zpáteční přepravě.

### § 3.

(1) Půjčovné činí:

| a) | při dodávkách lihu: |  |
|---|---|---|
|  | ze železničních kotlových vozů (cisteren) | Kčs 2,— |
|  | za každý i započatý hl dodaného lihu |  |
|  | z ostatních dopravních nádob (sudů, konví a j.) |  |
|  | při dodávce: |  |
|  | do 50 l alk. | Kčs 5,— |
|  | za nádobu, |  |
|  | přes 50 l alk. | Kčs 7,— |
|  | za každý i započatý hl dodaného lihu, |  |
| b) | při dodávkách přiboudliny: |  |
|  | ze všech dopravních nádob | Kčs 7,— |
|  | za každých i započatých 100 kg čisté váhy. |  |

(2) Při pozdějším vrácení nádob, než uvedeno v § 2, platí odběratel zdržné, a to:

a) ze železničních kotlových vozů (cisteren):

|  | za 2. až 6. den po přistavení drahou | Kčs | 80,— |
|---|---|---|---|
|  | za den a vůz, |  |  |
|  | za 7. až 10. den po přistavení drahou | Kčs | 130,— |
|  | za den a vůz, |  |  |
|  | za 11. a každý další den po přistavení drahou | Kčs | 200,— |
|  | za den a vůz, |  |  |
| b) | z ostatních dopravních nádob (sudů, konví a j.) | Kčs | 2,— |
|  | za nádobu a den bez ohledu na velikost nádoby. |  |  |

(3) Zdržné se počítá do dne, kdy byl obal odevzdán železnici k zpáteční přepravě, nebo do skladu, z něhož byl líh dodán. Den odevzdání obalu se včítá do lhůty pro výpočet zdržného.

(4) Stojné, počítané železnicí, hradí odběratel.

### § 4.

(1) Obaly je nutno vrátiti v řádném stavu:

a) z dodávek lihu přes 280 l alk. nevyplaceně do železniční stanice dodávajícího skladu, po příp. do jiné železniční stanice určené dodavatelem,

b) z dodávek lihu do 280 l alk. vyplaceně do železniční stanice, skladu, z něhož byl líh dodán,

c) ze všech místních dodávek lihu (bez ohledu na velikost dodávky) vyplaceně do skladu, z něhož byl líh dodán,

d) z dodávek přiboudliny vždy vyplaceně do železniční stanice dodávajícího skladu, při místních dodávkách vyplaceně do skladu, z něhož byla přiboudlina dodána.

(2) Při zničení nebo ztrátě půjčeného obalu se zdržné platí až do dne, kdy odběratel uvědomí dodavatele o zničení nebo ztrátě obalu.

### § 5.

Přestupky ustanovení této vyhlášky se trestají podle § 11 vládního nařízení č. 235/1949 Sb.

### § 6.

(1) Tato vyhláška nabývá účinnosti dne 31. července 1950 a platí na celém státním území.

(2) Ustanovení odporující této vyhlášce se zrušují.
