# Vyhláška ministerstva vnitřního obchodu o úplatách za půjčení obalů při dodávkách lihu a přiboudliny a o vracení těchto obalů.

472\. *(účinnost od 1950-07-31)*

VYHLÁŠKA *(účinnost od 1950-07-31)*

ministerstva vnitřního obchodu *(účinnost od 1950-07-31)*

ze dne 26. července 1950. *(účinnost od 1950-07-31)*

o úplatách za půjčení obalů při dodávkách lihu a přiboudliny a o vracení těchto obalů. *(účinnost od 1950-07-31)*

Ministerstvo vnitřního obchodu stanoví v dohodě se státním úřadem plánovacím podle § 2 odst. 2 a § 5 odst. 1 a § 7 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen: *(účinnost od 1950-07-31)*

### § 1. *(účinnost od 1950-07-31)*

Ustanovení této vyhlášky se vztahují na tyto druhy obalů: *(účinnost od 1950-07-31)*

a) železniční kotlové vozy (cisterny), *(účinnost od 1950-07-31)*

b) kovové a dřevěné sudy, *(účinnost od 1950-07-31)*

c) plechové konve, *(účinnost od 1950-07-31)*

d) skleněné láhve (balony a demijony) a jiné, *(účinnost od 1950-07-31)*

které slouží k přepravě všech druhů lihu a přiboudliny. *(účinnost od 1950-07-31)*

### § 2. *(účinnost od 1950-07-31)*

(1) Příjemci dodávek lihu a přiboudliny jsou povinni vraceti půjčené obaly ihned po vyprázdnění v řádném stavu a to — pokud nebylo s dodavatelem písemně sjednáno nic jiného — v těchto lhůtách: *(účinnost od 1950-07-31)*

a) železniční kotlové vozy (cisterny) nejpozději následující všední den po dni přistavení drahou, *(účinnost od 1950-07-31)*

| b) ostatní obaly nejpozději | do 30 dnů, |
|---|---| *(účinnost od 1950-07-31)*

jež se počítají při dodávkách po železnici ode dne odevzdání zboží železnici k přepravě, při ostatních dodávkách ode dne převzetí zboží ze skladu dodávajícího místa. *(účinnost od 1950-07-31)*

(2) Při vracení obalů drahou je stanovená lhůta dodržena, byl-li před jejím uplynutím vyprázdněný obal odevzdán železnici k zpáteční přepravě. *(účinnost od 1950-07-31)*

### § 3. *(účinnost od 1950-07-31)*

(1) Půjčovné činí: *(účinnost od 1950-07-31)*

| a) | při dodávkách lihu: |  |
|---|---|---|
|  | ze železničních kotlových vozů (cisteren) | Kčs 2,— |
|  | za každý i započatý hl dodaného lihu |  |
|  | z ostatních dopravních nádob (sudů, konví a j.) |  |
|  | při dodávce: |  |
|  | do 50 l alk. | Kčs 5,— |
|  | za nádobu, |  |
|  | přes 50 l alk. | Kčs 7,— |
|  | za každý i započatý hl dodaného lihu, |  |
| b) | při dodávkách přiboudliny: |  |
|  | ze všech dopravních nádob | Kčs 7,— |
|  | za každých i započatých 100 kg čisté váhy. |  | *(účinnost od 1950-07-31)*

(2) Při pozdějším vrácení nádob, než uvedeno v § 2, platí odběratel zdržné, a to: *(účinnost od 1950-07-31)*

a) ze železničních kotlových vozů (cisteren): *(účinnost od 1950-07-31)*

|  | za 2. až 6. den po přistavení drahou | Kčs | 80,— |
|---|---|---|---|
|  | za den a vůz, |  |  |
|  | za 7. až 10. den po přistavení drahou | Kčs | 130,— |
|  | za den a vůz, |  |  |
|  | za 11. a každý další den po přistavení drahou | Kčs | 200,— |
|  | za den a vůz, |  |  |
| b) | z ostatních dopravních nádob (sudů, konví a j.) | Kčs | 2,— |
|  | za nádobu a den bez ohledu na velikost nádoby. |  |  | *(účinnost od 1950-07-31)*

(3) Zdržné se počítá do dne, kdy byl obal odevzdán železnici k zpáteční přepravě, nebo do skladu, z něhož byl líh dodán. Den odevzdání obalu se včítá do lhůty pro výpočet zdržného. *(účinnost od 1950-07-31)*

(4) Stojné, počítané železnicí, hradí odběratel. *(účinnost od 1950-07-31)*

### § 4. *(účinnost od 1950-07-31)*

(1) Obaly je nutno vrátiti v řádném stavu: *(účinnost od 1950-07-31)*

a) z dodávek lihu přes 280 l alk. nevyplaceně do železniční stanice dodávajícího skladu, po příp. do jiné železniční stanice určené dodavatelem, *(účinnost od 1950-07-31)*

b) z dodávek lihu do 280 l alk. vyplaceně do železniční stanice, skladu, z něhož byl líh dodán, *(účinnost od 1950-07-31)*

c) ze všech místních dodávek lihu (bez ohledu na velikost dodávky) vyplaceně do skladu, z něhož byl líh dodán, *(účinnost od 1950-07-31)*

d) z dodávek přiboudliny vždy vyplaceně do železniční stanice dodávajícího skladu, při místních dodávkách vyplaceně do skladu, z něhož byla přiboudlina dodána. *(účinnost od 1950-07-31)*

(2) Při zničení nebo ztrátě půjčeného obalu se zdržné platí až do dne, kdy odběratel uvědomí dodavatele o zničení nebo ztrátě obalu. *(účinnost od 1950-07-31)*

### § 5. *(účinnost od 1950-07-31)*

Přestupky ustanovení této vyhlášky se trestají podle § 11 vládního nařízení č. 235/1949 Sb. *(účinnost od 1950-07-31)*

### § 6. *(účinnost od 1950-07-31)*

(1) Tato vyhláška nabývá účinnosti dne 31. července 1950 a platí na celém státním území. *(účinnost od 1950-07-31)*

(2) Ustanovení odporující této vyhlášce se zrušují. *(účinnost od 1950-07-31)*
