# Vyhláška ministerstva zemědělství a lesního hospodářství o změně výkupních cen osiva některých léčivých a aromatických rostlin.

150\.

VYHLÁŠKA

ministerstva zemědělství a lesního hospodářství

ze dne 16. srpna 1957

o změně výkupních cen osiva některých léčivých a aromatických rostlin.

Ministerstvo zemědělství a lesního hospodářství vyhlašuje podle § 25 vládního nařízení č. 28/1954 Sb., o působnosti v oboru plánování a tvorby cen:

### Čl. I.

Výkupní ceny osiva dále uvedených léčivých a aromatických rostlin, stanovené v příloze vyhlášky ministerstva zemědělství č. 288/1953 Ú. l., o cenách osiva a sazenic léčivých a aromatických rostlin, se mění takto:

|  |  | Kčs |
|---|---|---|
| Heřmánek pravý | obchodní osivo | 200,— |
| Matricaria chamomilla L. | šlechtěné osivo II. jakost | 375,— |
| kozlík lékařský | obchodní osivo | 300,— |
| Valeriana officinalis L. | šlechtěné osivo II. jakost | 500,— |
| tymián obecný | obchodní osivo | 200,— |
| Thymus vulgaris L. | (šlechtěné osivo se nevykupuje). |  |

### Čl. II.

Tato vyhláška nabývá účinnosti dnem 22. srpna 1957.

První náměstek ministra:

Nepomucký v. r.
