# Vyhláška ministerstva zemědělství o spotřebitelských cenách samovazačových motouzů a provázkových povřísel.

231\.

VYHLÁŠKA

ministerstva zemědělství

ze dne 15. června 1951

o spotřebitelských cenách samovazačových motouzů a provázkových povřísel.

Ministerstvo zemědělství vyhlašuje podle § 7 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen:

### § 1.

(1) Nejvyšší spotřebitelské ceny samovazačových motouzů a provázkových povřísel se stanoví takto:

| A. | Motouzy: | Kčs za 1 kg brutto/netto váhy |
|---|---|---|
|  | 1. motouz ze sisalu o výdejnosti cca 280 až 500 m/1 kg | 65,— |
| 2. motouz ze sisalu o výdejnosti cca 600 m/1 kg | 80,— |
| 3. motouz konopný o výdejnosti cca 350 až 400 m/1 kg | 50,— |
| 4. motouz kombinovaný (z nátronového papíru a lněné koudele) o výdejnosti cca 320 m/1 kg | 34.— |
| 5. motouz z nátronového papíru o výdejnosti cca 280 m/1 kg | 26,— |
| B. | Provázková povřísla: | Kčs za tisíc kusů: |
|  | 1. papírová s kolíčky (z nátronového papíru) | 321,— |
| 2. papírová s kolíčky (ze sulfitového papíru) | 280,— |
| 3. sisalová s kolíčky (z nového motouzu) | 443,— |
| 4. sisalová s kolíčky (z odpadového motouzu) | 369,— |
| 5. sisalová s očky (z odpadového motouzu) | 314,— |
| 6. konopná s kolíčky (z odpadového motouzu) | 283,— |
| 7. konopná s očky (z odpadového motouzu) | 227,— |
| 8. konopná s kolíčky (z nového motouzu) | 400,— |
| 9. jutová s kolíčky (z nového motouzu) | 360,— |

(2) Ceny se rozumějí včetně všeobecné daně. K cenám motouzů nesmí býti připočítávána žádná přirážka za vyschnutí.

### § 2.

Tato vyhláška nabývá účinnosti dnem 19. června 1951.

Ministr:

Ďuriš v. r.
