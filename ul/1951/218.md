# Redakční sdělení ministerstva vnitra o opravě tiskových chyb ve vyhlášce ministerstev zdravotnictví a zemědělství č. 199/1951 Ú. l. I, o výkupních cenách léčivých rostlin.

218\.

REDAKČNÍ SDĚLENÍ

ministerstva vnitra

ze dne 5. června 1951

o opravě tiskových chyb ve vyhlášce ministerstev zdravotnictví a zemědělství č. 199/1951 Ú. l. I, o výkupních cenách léčivých rostlin.

V příloze vyhlášky ministerstev zdravotnictví a zemědělství č. 199/1951 Ú. l. I opravují se tiskové chyby v položkách: Bedrník obecný, Máta kadeřavá a Měsíček zahradní. Uvedené položky zní správně:

| „Bedrník obecný, b. větší | nať bedrníková listnatá (nejvýše 50 cm dlouhá) | 18.— |
|---|---|---|
| Pimpinella saxifraga L., | Herba Pimpinellae |  |
| Pimpinella maior (L.) HUDS |  |  |
|  | kořen bedrníkový Radix Pimpinelae | 32.—“ |
| „Máta kadeřavá Menta crispa L. | listy máty kadeřavé Folia menthae crispae nať máty kadeřavé Herba menthae crispae | 50.— 35.—“ |
| „Měsíček zahradní Calendula officinalis L. | květy měsíčkové se zákrovem Flores calendulae c. calicibus | 40.— |
|  | květy měsíčkové bez zákrovu Flores calendulae s. calicibus | 120.—“ |

Za ministra:

Jarý v. r.
