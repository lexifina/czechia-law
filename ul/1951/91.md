# Vyhláška ministerstev vnitřního obchodu a těžkého průmyslu, kterou se mění vyhláška o úpravě dodávek a odběru hodinářského a klenotnického zboží.

91\.

VYHLÁŠKA

ministerstev vnitřního obchodu a těžkého průmyslu

ze dne 13. února 1951,

kterou se mění vyhláška o úpravě dodávek a odběru hodinářského a klenotnického zboží.

Ministerstva vnitřního obchodu a těžkého průmyslu stanoví podle §§ 1 a 2 zákona č. 160/1949 Sb., o vnitřním obchodě, a podle §§ 1 až 3 dekretu presidenta republiky č. 109/1945 Sb., o řízení výroby:

### § 1.

Vyhláška ministerstev vnitřního obchodu a průmyslu č. 896/1949 Ú. l. I, o úpravě dodávek a odběru hodinářského a klenotnického zboží, se mění takto:

1\. § 1 odst. 3 zní:

„(3) Ustanovení odstavců 1 a 2 neplatí pro

a) zboží určené pro vývoz,

b) zboží určené k přímému použití ve výrobním postupu, k vybudování nebo k údržbě výrobních zařízení, je-li odběratelem zboží výrobní podnik národní, komunální nebo družstevní a jestliže provedení dodávky přímo výrobním podnikem nebo výsadní společností pro zahraniční obchod je hospodářsky účelné“.

2\. Ze seznamu zboží, jenž tvoří přílohu 1 vyhlášky, se vypouštějí položky

| 17 | 94 |  | výrobky brusíren drahokamů a polodrahokamů |
|---|---|---|---|
|  |  | 0 | broušené drahokamy přírodní, kromě průmyslových diamantů |
|  |  | 1 | broušené drahokamy synthetické, kromě ložiskových kamenů |
|  |  | 2 | broušené polodrahokamy |
|  |  | 9 | ostatní zde neuvedené, kromě kamenů sloužících jinému účelu než ozdobnému. |

### § 2.

Tato vyhláška nabývá účinnosti dnem vyhlášení.

Ministr těžkého průmyslu:

Kliment v. r.

Ministr vnitřního obchodu:

Krajčír v. r.
