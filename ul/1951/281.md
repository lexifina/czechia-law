# Vyhláška ministerstva zemědělství, kterou se mění a doplňuje vyhláška o cenách zeleninových semen a sadby.

281\.

VYHLÁŠKA

ministerstva zemědělství

ze dne 19. července 1951,

kterou se mění a doplňuje vyhláška o cenách zeleninových semen a sadby.

Ministerstvo zemědělství vyhlašuje podle § 7 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen:

### Čl. I.

Příloha k vyhlášce ministerstva zemědělství č. 114/1951 Ú. l. I, o cenách zeleninových semen a sadby, se mění a doplňuje takto:

1\. Ustanovení o cenách květáku zní:

Ceny v Kčs za 1 kg

| Druh a odrůda | Množitelská cena | Prodejní cena ČSSS, n. p. | Prodejní cena Ústředí | Spotřebitelská cena nad 250 g do 250 g |
|---|---|---|---|---|
| Květák |  |  |  |  |  |
| semeno šlechtěné původní | 3.000 | 3.742 | 4.183 | 4.687 | 4.987 |

2\. Za ustanovení o cenách papriky zeleninové se vkládá toto ustanovení:

Ceny v Kčs za 1 kg

| Druh a odrůda | Množitelská cena | Prodejní cena ČSSS, n. p. | Prodejní cena Ústředí | Spotřebitelská cena nad 250 g do 250 g |
|---|---|---|---|---|
| Paprika kořeninová |  |  |  |  |  |
| semeno šlechtěné |  |  |  |  |  |
| původní | 330 | 445 | — | — | — |
| krajová odrůda, semeno uznané | 230 | 270 | — | — | — |
| obchodní osivo | 110 | — | — | — | — |

3\. Ustanovení o cenách anýzu a fenyklu se vypouštějí.

### Čl. II.

Tato vyhláška nabývá účinnosti dnem 24. července 1951.

Za ministra:

Dr. Ing. Koťátko v. r.
