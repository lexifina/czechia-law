# Vyhláška nejvyššího úřadu cenového, kterou se mění vyhláška nejvyššího úřadu cenového ze dne 30. prosince 1948, o nejvyšších procentních přirážkách v obchodu se skleněným, porcelánovým, kameninovým a keramickým zbožím.

521\.

VYHLÁŠKA

nejvyššího úřadu cenového

ze dne 21. dubna 1949,

kterou se mění vyhláška nejvyššího úřadu cenového ze dne 30. prosince 1948, o nejvyšších procentních přirážkách v obchodu se skleněným, porcelánovým, kameninovým a keramickým zbožím.

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto:

### Čl. I.

V § 2 vyhlášky nejvyššího úřadu cenového ze dne 30. prosince 1948, č. 86 Ú. l. I z roku 1949, o nejvyšších procentních přirážkách v obchodu se skleněným, porcelánovým, kameninovým a keramickým zbožím se mění nejvýše přípustné procentní obchodní přirážky (obchodní rozpětí) u níže uvedených položek takto:

| Plán. skupina |  | Druh zboží | Obchodní rozpětí v % z nákupní ceny |
|---|---|---|---|
|  |  | ve velkoobchodu | v maloobchodu |
|  |  | I. Duté sklo: |  |  |
| 21 | 401 |  | Zušlechtěné sklo olovnaté | 10 | 25 |
|  |  | III. Drobné skleněné zboží: |  |  |
| 21 | 31 | } | Perle, knoflíky, rocailles, kameny, kroužky, chatony, pera na psaní a pod. | 19 | 35 |
| 21 | 42 |
| 21 | 42 |  | Figurky, květinky a pod. | 19 | 35 |
| 21 | 42 |  | Skleněná bižuterie, jakož i t. zv. jablonecké výrobky, převážně ze skla | 22 | 42 |

Tato vyhláška nabývá účinnosti dnem 25. dubna 1949.
