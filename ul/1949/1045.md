# Redakční sdělení ministerstva vnitra o opravě tiskových chyb ve vyhlášce ministerstev vnitřního obchodu a průmyslu ze dne 13. října 1949, č. 1035 Ú. l. I, o změně bodových hodnot obuvi.

1045\.

REDAKČNÍ SDĚLENÍ

ministerstva vnitra

ze dne 20. října 1949

o opravě tiskových chyb ve vyhlášce ministerstev vnitřního obchodu a průmyslu ze dne 13. října 1949, č. 1035 Ú. l. I, o změně bodových hodnot obuvi.

V příloze vyhlášky č. 1035/1949 Ú. l. I (seznamu vázané obuvi) se opravují tyto tiskové chyby:

1\. U č. IV. (Obuv gumová, chlapecká a dívčí, celopryžová) se opravuje plán. číslo „27 11 90“ na„27 11 60“.

| 2. | U plán. čísla | 27 | 11 | 00 až 06 |
|---|---|---|---|---|
|  |  | 27 | 11 | 30 až 38 |
|  |  | 27 | 11 | 60 až 62 |
|  |  | 27 | 11 | 80 až 85 |
|  |  | 27 | 11 | 90 až 95 |

se opravuje bodová hodnota ze dvou bodů na pět bodů.

Za ministra:

Dr. Myšák v. r.
