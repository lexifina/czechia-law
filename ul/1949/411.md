# Vyhláška nejvyššího úřadu cenového o obchodním rozpětí při prodeji suchých (práškových) barev.

411\.

VYHLÁŠKA

nejvyššího úřadu cenového

ze dne 9. března 1949

o obchodním rozpětí při prodeji suchých (práškových) barev.

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto:

### § 1.

Při prodeji suchých (práškových) barev smějí být k netto nákupním cenám bez všeobecné daně připočtena nejvýše tato obchodní rozpětí:

| 1. | velkoobchodem |  |
|---|---|---|
|  | při obchodech traťových | 4%, |
|  | při obchodech ze skladu | 15%, |
| 2. | maloobchodem |  |
|  | při prodeji 50 kg a více jedné barvy | 20%, |
|  | při prodeji od 1 kg do 49 kg jedné barvy | 30%, |
|  | při prodeji pod 1 kg jedné barvy | 40%. |

### § 2.

Při dodávkách velkoobchodem rozumějí se ceny ze skladu velkoobchodu, u traťových obchodů ze skladu dodavatele.

### § 3.

Přestupky ustanovení této vyhlášky se trestají podle části čtvrté vládního nařízení o zřízení nejvyššího úřadu cenového a podle předpisů toto nařízení měnících nebo doplňujících.

### § 4.

Tato vyhláška nabývá účinnosti dnem vyhlášení. Zároveň se ruší ustanovení výměru nejvyššího úřadu cenového ze dne 28. listopadu 1945, č. j. 50.433-V/2-1945, o cenách suchých (práškových) barev, pokud se týkají velkoobchodního a maloobchodního rozpětí.
