# Vyhláška osidlovacího úřadu a Fondu národní obnovy v Praze o nové územní organisaci oblastních úřadoven osidlovacího úřadu a Fondu národní obnovy vzhledem k zákonu ze dne 21. prosince 1948, č. 280 Sb., o krajském zřízení.

334\.

VYHLÁŠKA

osidlovacího úřadu a Fondu národní obnovy v Praze

ze dne 7. února 1949

o nové územní organisaci oblastních úřadoven osidlovacího úřadu a Fondu národní obnovy vzhledem k zákonu ze dne 21. prosince 1948, č. 280 Sb., o krajském zřízení.

Podle § 7 statutu osidlovacího úřadu v Praze (příloha k vyhlášce ministra vnitra ze dne 24. září 1945, č. 72 Sb.) se stanoví:

### § 1.

Obvody místní působnosti oblastních úřadoven osidlovacího úřadu a Fondu národní obnovy se upravují takto:

| Oblastní úřadovna: | Obvod její místní působnosti tvoří územní obvod kraje: |
|---|---|
| Praha | Pražského |
| České Budějovice | Českobudějovického |
| Plzeň | Plzeňského |
| Karlovy Vary | Karlovarského |
| Teplice | Ústeckého |
| Liberec | Libereckého |
| Trutnov | Hradeckého |
| Pardubice | Pardubického |
| Brno | Jihlavského a Brněnského |
| Olomouc | Olomouckého a Gottwaldovského |
| Opava | Ostravského. |

### § 2.

Dosavadní ustanovení stanovící místní působnost oblastních úřadoven, jež jsou v rozporu se shora uvedenou úpravou, se zrušují.

### § 3.

Tato vyhláška nabývá účinnosti dnem vyhlášení.
