# Vyhláška nejvyššího úřadu cenového, kterou se mění vyhláška o obchodních přirážkách v obchodu s brašnářskými a koženými galanterními výrobky.

430\. *(účinnost od 1947-05-05)*

Vyhláška *(účinnost od 1947-05-05)*

nejvyššího úřadu cenového *(účinnost od 1947-05-05)*

ze dne 22. dubna 1947, *(účinnost od 1947-05-05)*

kterou se mění vyhláška o obchodních přirážkách v obchodu s brašnářskými a koženými galanterními výrobky. *(účinnost od 1947-05-05)*

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto: *(účinnost od 1947-05-05)*

### Článek I. *(účinnost od 1947-05-05)*

Příloha k vyhlášce nejvyššího úřadu cenového ze dne 24. března 1947 o obchodních přirážkách v obchodu s brašnářskými a koženými galanterními výrobky (Ú. l. I č. 43/1947, běž. č. 275) zní: *(účinnost od 1947-05-05)*

|  | Maximální procentní přirážka v místní třídě: |
|---|---|
|  | I. | II. |
| A. |  |  |
| Běžné zboží. |  |  |
| Trhovky (otevřené nákupní tašky), batohy a chlebníky. Náprsnice, dolarky, peněženky, visitky ze skopovice, králičin, rybin, imitace a štípenky | 25% | 20% |
| Desky a pouzdra na doklady a průkazy (ze štípenky, králičin, skopovice, rybin a imitace) |
| Kufry lepenkové, kufry fibrové, kočárkové brašny a ochranné řemínky do dětských kočárků |
| Školní brašny a penály. Nezakládané diplomatky a aktovky z imitací a štípenky |
| Dámské a dětské kabelky všeho druhu z plátna a imitací. |
| B. | 30% | 25% |
| Střední zboží. |
| Dámské a dětské kabelky všeho druhu z králičiny, skopovice, rybin |
| Brašny uzavřené z plátna a imitací |
| Sáčky na tabák a na klíče |
| Pouzdra na brýle, na nože, hřebeny a zrcátka |
| Řemínky všeho druhu k hodinkám, pánské a sportovní pásky |
| Pouzdra na doutníky a cigarety z králičiny, skopovice, rybin a imitace |
| Pouzdra na klobouky, košile, límce, kravaty a kapesníky z lepenky, plátna a imitací, králičin, štípenky |
| Manikury, kapesní toalety, šitíčka a pouzdra na skvosty, flakony, cestovní láhve z plátna, imitací, králičin, štípenky |
| Zakládané diplomatky, aktovky a vzorkovnice z plátna, imitací a štípenky |
| Kufry plátěné a z imitací, kabely z voskovaného plátna na koupání, kožené míče a jiné sportovní potřeby z kůže. |
| C. | 35% | 30%. |
| Výběrové zboží. |
| Náprsnice, dolarky, peněženky, visitky, desky na doklady a na průkazy z vepřovice, kozinky, hověziny |
| Nákupní brašny (uzavřené) kožené z vepřovice, hověziny a koziny |
| Kabelky všeho druhu z vepřovice, koziny, hověziny, koniny, nappy, zámiše |
| Pouzdra na doklady, doutníky a cigarety z vepřovice, koziny a hověziny, pudřenky všeho druhu |
| Dámské pásky, kožené květiny a ozdobné předměty z kůže |
| Potřeby všech druhů pro psy |
| Pouzdra na zbraně, náboje, lovecké brašny |
| Pouzdra na fotografické aparáty a potřeby |
| Zakládané diplomatky, aktovky a vzorkovnice z vepřovice, koziny, skopovice, koniny a hověziny |
| Kufry plátěné lemované kůží a s koženými držátky. | *(účinnost od 1947-05-05)*
