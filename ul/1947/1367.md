# Vyhláška nejvyššího úřadu cenového o odměnách za práce architektonické, konané členy Svazu československých výtvarných umělců, a o odměnách za odhady realit.

1367\.

Vyhláška

nejvyššího úřadu cenového

ze dne 23. prosince 1947

o odměnách za práce architektonické, konané členy Svazu československých výtvarných umělců, a o odměnách za odhady realit.

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízeni o zřízení nejvyššího úřadu cenového toto:

### § 1.

(1) Ustanovení vyhlášky nejvyššího úřadu cenového ze dne 30. června 1947, č. 743 Ú. l. I, o snížení odměn architektů, kteří nejsou členy Inženýrské komory, se nevztahují na architekty-projektanty, kteří jsou členy Svazu československých výtvarných umělců.

(2) Ustanovení vyhlášky nejvyššího úřadu cenového ze dne 29. března 1947, č. 337 Ú. l. I, o snížení odměn v oboru svobodných a jim příbuzných povolání, se nevztahují na členy Svazu československých výtvarných umělců, pokud jsou zároveň členy Inženýrské komory, v případech, kdy vypočítávají svou odměnu za vyhotovení projektu nebo jeho části procentní sazbou z rozpočteného nákladu projektovaného díla.

### § 2.

Členové Svazu československých výtvarných umělců smějí účtovati sazby podle „Ustanovení o honorářích za práce architektonické“, části B (práce při úpravě a stavbě měst) zvýšené nejvýše o 150%, sazby podle části D (všeobecné sazby) zvýšené nejvýše takto:

| I. | Sazby podle času: |  |
|---|---|---|
|  | u výkonů, kde jde o hodnotu věci do 50.000 Kčs | o 100%, |
|  | u výkonů, kde jde o hodnotu věci přes 50.000 Kčs | o 60%, |
|  | rozmluvy a porady v kanceláři | o 100%. |
| II. | Poplatky za písařské práce | o 150%, |
|  | poplatky za kreslířské práce | o 100%. |
| III. | Cestovné a poplatky vzdálenostní: |  |
|  | stravné | o 200%, |
|  | nocležné (poplatek za nocleh) | o 150%, |
|  | ostatní sazby oddílu III. | o 100%. |

### § 3.

Honorářové sazby pro odhad realit (sazby části C „Ustanovení o honorářích za práce architektonické“), stanovené v promile, smějí býti v případech, kdy se odhadem zjišťuje cena ke dni 20. června 1939, zvýšeny nejvýše o 75%.

### § 4.

Přestupky ustanovení této vyhlášky se trestají podle části čtvrté vládního nařízení o zřízení nejvyššího úřadu cenového a podle předpisů toto nařízení měnících nebo doplňujících.

### § 5.

Tato vyhláška nabývá účinnosti dnem 1. ledna 1948.

Za předsedu nejvyššího úřadu cenového:
