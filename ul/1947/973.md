# Vyhláška československého monopolu lihového o prodejních cenách lihu.

973\.

Vyhláška

československého monopolu lihového

ze dne 17. září 1947

o prodejních cenách lihu.

Československý monopol lihový stanoví podle § 98 zákona ze dne 19. února 1946. č. 30 Sb., se souhlasem nejvyššího úřadu cenového a pověřence výživy, prodejní ceny lihu takto:

### § 1.

Plná prodejní cena čistého lihu k výrobě lihovin, trestí, léčiv, voňavek a pod.:

|  |  |  | Maloprodej: |  |  |  |  |
|---|---|---|---|---|---|---|---|
|  |  | 1 l | prostor | Kčs | 310.— | } | za prostorový litr 95 obj. % z dodacího místa |
| přes | 1 l | do 5 l | prostor | Kčs | 305.50 |
| přes | 5 l | do 10 l | prostor | Kčs | 302.50 |
| přes | 10 l | do 25 l | prostor | Kčs | 301.50 |
| od | 25 l | do 50 l | alkoholu | Kčs | 309.— | } | za litr alkoholu z dodacího místa |
| přes | 50 l | do 100 l | alkoholu | Kčs | 307.— |  |  |
| přes | 100 l | do 150 l | alkoholu | Kčs | 306.50 |  |  |
| přes | 150 l | do 280 l | alkoholu | Kčs | 306.— |  |  |
|  |  |  | Velkoprodej: |  |  |  |  |
| přes | 280 l |  | alkoholu | Kčs | 300.— | { | za litr alkoholu vyplaceně do stanice příjemce. |

Přirážka za bezvodý líh, pokud se dodává k shora uvedeným účelům, Kčs 0.50 za litr alkoholu.

### § 2.

Prodejní cena čistého lihu k výrobě octa:

|  | Maloprodej: |  |  |
|---|---|---|---|
| přes 25 l do 100 l alkoholu | Kčs 20.90 | } | za litr alkoholu z dodacího místa. |
| přes 100 l do 280 l alkoholu | Kčs 20.70 |
| Velkoprodej: |
| přes 280 l alkoholu | Kčs 20.— | { | za litr alkoholu vyplaceně do stanice příjemce. |

Surový líh, pokud se k výrobě octa dodává, účtuje se o Kčs 0.20 za litr alkoholu levněji.

### § 3.

Prodejní cena lihu k čištění, topení, vaření, osvětlování, k účelům živnostenským nebo vědeckým, denaturovaného všeobecným nebo zvláštním denaturačním prostředkem, k zvláštní denaturaci nebo nedenaturovaného:

|  | Maloprodej: |  |  |
|---|---|---|---|
| do 25 l prostor | Kčs 10.60 | { | za prostorový litr 95 obj. % z dodacího místa |
| přes 25 l do 100 l alkoholu | Kčs 10.90 | } | za litr alkoholu |
| přes 100 l do 280 l alkoholu | Kčs 10.70 | z dodacího místa. |
| Velkoprodej: |
| přes 280 l alkoholu | Kčs 10.— | { | za litr alkoholu vyplaceně do stanice příjemce |
| Zvláštní cena lihu k pálení pro rozdělovače (velkoobchodníky) všeobecně denaturovaného lihu: |
| přes 280 l alkoholu | Kč 9.70 | { | za litr alkoholu vyplaceně do stanice příjemce |
| cena, za kterou rozdělovač (velkoobchodník) dodává líh k pálení maloobchodníkům | Kčs 10.— | } | za prostorový litr 95 obj. % franko dům, |
| cena, za kterou maloobchodník prodává líh k pálení spotřebitelům | Kč 11.20 | } | za prostorový litr 95 obj. %. |

Přirážka za bezvodý líh, pokud se dodává ke shora uvedeným účelům, Kčs 0.50 za litr alkoholu.

### § 4.

Prodejní cena bezvodého lihu k mísení s pohonnými látkami u oprávněných odběratelů bez kontrolního poplatku:

| Maloprodej: |
|---|
| přes 25 l do 100 l alkoholu | Kčs 10.90 | za litr alkoholu z dodacího místa. |
| přes 100 l do 280 l alkoholu | Kčs 10.70 |
| Velkoprodej: |
| přes 280 l v sudech | Kčs 10.25 | za litr alkoholu vyplaceně do stanice příjemce |
| v jímkách nejméně 100 hl | Kčs 10.— |

### § 5.

1\. Tato vyhláška platí pro celé území Československé republiky a nabývá účinnosti dne 22. září 1947.

2\. Týmž dnem pozbývají platnosti vyhlášky československého monopolu lihového ze dne 25. září 1946 o prodejních cenách lihu (Ú. l. I č. 179/1946, běž. č. 1829 a Úr. vest. č. 69/1946, bež. č. 1620) a ze dne 28. března 1947 o změně prodejních cen lihu (Ú. l. I č. 44/1947, běž. č. 299 a Úr. vest. č. 17/1947, běž. č. 246).
