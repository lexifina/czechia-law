# Vyhláška československého monopolu lihového o prodejních cenách lihu.

973\. *(účinnost od 1947-09-22)*

Vyhláška *(účinnost od 1947-09-22)*

československého monopolu lihového *(účinnost od 1947-09-22)*

ze dne 17. září 1947 *(účinnost od 1947-09-22)*

o prodejních cenách lihu. *(účinnost od 1947-09-22)*

Československý monopol lihový stanoví podle § 98 zákona ze dne 19. února 1946. č. 30 Sb., se souhlasem nejvyššího úřadu cenového a pověřence výživy, prodejní ceny lihu takto: *(účinnost od 1947-09-22)*

### § 1. *(účinnost od 1947-09-22)*

Plná prodejní cena čistého lihu k výrobě lihovin, trestí, léčiv, voňavek a pod.: *(účinnost od 1947-09-22)*

|  | Maloprodej: |  |  |
|---|---|---|---|
| 1 l prostor. | Kčs 272.— | } | za prostorový litr 95 obj. % z dodacího místa |
| přes 1 l do 5 l prostor. | Kčs 267.50 |
| přes 5 l do 10 l prostor. | Kčs 264.50 |
| přes 10 l do 25 l prostor. | Kčs 263.50 |
| od 25 l do 50 l alkoholu | Kčs 269.— | } | za litr alkoholu z dodacího místa. |
| přes 50 l do 100 l alkoholu | Kčs 267.— |
| přes 100 l do 150 l alkoholu | Kčs 266.50 |
| přes 150 l do 280 l alkoholu | Kčs 266.— |
| Velkoprodej: |
| přes 280 l alkoholu | Kčs 260.— | { | za litr alkoholu vyplaceně do stanice příjemce. | *(účinnost od 1947-09-22)*

Přirážka za bezvodý líh, pokud se dodává k shora uvedeným účelům, Kčs 0.50 za litr alkoholu. *(účinnost od 1947-09-22)*

### § 2. *(účinnost od 1947-09-22)*

Prodejní cena čistého lihu k výrobě octa: *(účinnost od 1947-09-22)*

|  | Maloprodej: |  |  |
|---|---|---|---|
| přes 25 l do 100 l alkoholu | Kčs 20.90 | } | za litr alkoholu z dodacího místa. |
| přes 100 l do 280 l alkoholu | Kčs 20.70 |
| Velkoprodej: |
| přes 280 l alkoholu | Kčs 20.— | { | za litr alkoholu vyplaceně do stanice příjemce. | *(účinnost od 1947-09-22)*

Surový líh, pokud se k výrobě octa dodává, účtuje se o Kčs 0.20 za litr alkoholu levněji. *(účinnost od 1947-09-22)*

### § 3. *(účinnost od 1947-09-22)*

Prodejní cena lihu k čištění, topení, vaření, osvětlování, k účelům živnostenským nebo vědeckým, denaturovaného všeobecným nebo zvláštním denaturačním prostředkem, k zvláštní denaturaci nebo nedenaturovaného: *(účinnost od 1947-09-22)*

|  | Maloprodej: |  |  |
|---|---|---|---|
| do 25 l prostor | Kčs 10.60 | { | za prostorový litr 95 obj. % z dodacího místa |
| přes 25 l do 100 l alkoholu | Kčs 10.90 | } | za litr alkoholu |
| přes 100 l do 280 l alkoholu | Kčs 10.70 | z dodacího místa. |
| Velkoprodej: |
| přes 280 l alkoholu | Kčs 10.— | { | za litr alkoholu vyplaceně do stanice příjemce |
| Zvláštní cena lihu k pálení pro rozdělovače (velkoobchodníky) všeobecně denaturovaného lihu: |
| přes 280 l alkoholu | Kč 9.70 | { | za litr alkoholu vyplaceně do stanice příjemce |
| cena, za kterou rozdělovač (velkoobchodník) dodává líh k pálení maloobchodníkům | Kčs 10.— | } | za prostorový litr 95 obj. % franko dům, |
| cena, za kterou maloobchodník prodává líh k pálení spotřebitelům | Kč 11.20 | } | za prostorový litr 95 obj. %. | *(účinnost od 1947-09-22)*

Přirážka za bezvodý líh, pokud se dodává ke shora uvedeným účelům, Kčs 0.50 za litr alkoholu. *(účinnost od 1947-09-22)*

### § 4. *(účinnost od 1947-09-22)*

Prodejní cena bezvodého lihu k mísení s pohonnými látkami u oprávněných odběratelů bez kontrolního poplatku: *(účinnost od 1947-09-22)*

| Maloprodej: |
|---|
| přes 25 l do 100 l alkoholu | Kčs 10.90 | za litr alkoholu z dodacího místa. |
| přes 100 l do 280 l alkoholu | Kčs 10.70 |
| Velkoprodej: |
| přes 280 l v sudech | Kčs 10.25 | za litr alkoholu vyplaceně do stanice příjemce |
| v jímkách nejméně 100 hl | Kčs 10.— | *(účinnost od 1947-09-22)*

### § 5. *(účinnost od 1947-09-22)*

1\. Tato vyhláška platí pro celé území Československé republiky a nabývá účinnosti dne 22. září 1947. *(účinnost od 1947-09-22)*

2\. Týmž dnem pozbývají platnosti vyhlášky československého monopolu lihového ze dne 25. září 1946 o prodejních cenách lihu (Ú. l. I č. 179/1946, běž. č. 1829 a Úr. vest. č. 69/1946, bež. č. 1620) a ze dne 28. března 1947 o změně prodejních cen lihu (Ú. l. I č. 44/1947, běž. č. 299 a Úr. vest. č. 17/1947, běž. č. 246). *(účinnost od 1947-09-22)*

Ing. Šála v. r. *(účinnost od 1947-09-22)*
