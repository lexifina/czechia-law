# Vyhláška nejvyššího úřadu cenového, kterou se mění vyhláška nejvyššího úřadu cenového o cenách lesních plodů domácího původu.

762\.

Vyhláška

nejvyššího úřadu cenového

ze dne 18. července 1947,

kterou se mění vyhláška nejvyššího úřadu cenového o cenách lesních plodů domácího původu.

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto:

### Článek I.

V § 1, odst. 1 vyhlášky nejvyššího úřadu cenového ze dne 21. června 1947 o cenách lesních plodů domácího původu (Ú. l. I č. 98/1947, běž. č. 656) se mění nejvyšší sběračské a nejvyšší spotřebitelské ceny trhaných borůvek a lesních malin a stanoví se takto:

| Druh | Borůvky trhané | Lesní maliny |
|---|---|---|
| lesních plodin | Kčs | Kčs |
| Nejvyšší cena sběračská |  |  |
|  | za 100 kg | 1.000.— | 1.100.— |
| Nejvyšší cena spotřebitelská |  |  |
|  | za 1 kg | 14.80 | 15.80 |

### Článek II.

Tato vyhláška nabývá účinnosti dnem vyhlášení.

Za předsedu nejvyššího úřadu cenového:

Dr. Benda v. r.
