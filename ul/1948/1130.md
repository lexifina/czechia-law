# Vyhláška zemského národního výboru v Praze o poškozených obcích, pro které platí ustanovení části I zákona č. 86/46 Sb., o stavební obnově, ve znění zákona č. 115/1947 Sb.

1130\.

VYHLÁŠKA

zemského národního výboru v Praze

ze dne 18. května 1948

o poškozených obcích, pro které platí ustanovení části I zákona č. 86/46 Sb., o stavební obnově, ve znění zákona č. 115/1947 Sb

### Čl. I.

Zemský národní výbor v Praze rozhodl a vyhlašuje na podkladě § 4, odst. 1 zákona ze dne 12. dubna 1946, č. 86 Sb., o stavební obnově, ve znění zákona ze dne 12. června 1947, č. 115 Sb., že ustanovení tohoto zákona platí pro tyto obce:

|  | Jméno obce: | Správní okres: |
|---|---|---|
| 494. | Konstantinovy Lázně | Planá |
| 495. | Křečovice | Benešov |
| 496. | Dražice nad Jizerou | Mladá Boleslav |
| 497. | Borek | Tachov |
| 498. | Bohuslav | Tachov |

|  | Správní okres: | Jméno obce: |
|---|---|---|
| 499. | Frauenreith | Tachov |
| 500. | Hostka | Tachov |
| 501. | Jalový Dvůr | Tachov |
| 502. | Labuť | Tachov |
| 603. | Nový Losimtál | Tachov |
| 504. | Olešná | Tachov |
| 505. | Ostrov | Tachov |
| 506. | Schönbrunn | Tachov |
| 507. | Skviřín | Tachov |
| 508. | Souměř | Tachov |

### Čl. II.

Tato vyhláška jest doplněním předchozích vyhlášek a může býti dalšími vyhláškami měněna nebo doplněna.

### Čl. III.

Vyhláška nabývá účinnosti dnem vyhlášení.
