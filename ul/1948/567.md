# Vyhláška ministra vnitra o úpravě obvodů statistické služby okresních národních výborů v zemi České.

567\.

VYHLÁŠKA

ministra vnitra

ze dne 8. dubna 1948

o úpravě obvodů statistické služby okresních národních výborů v zemi České.

V dohodě s předsedou vlády stanovím podle § 9 vládního nařízení ze dne 6. března 1936, č. 51 Sb., o organisaci policejní správy a služby a o některých jiných opatřeních v oboru vnitřní správy:

## I.

Položky č. 24, 30 a 31 části I vyhlášky ministra vnitra ze dne 27. června 1946, č. 1500 Ú. l. I, o úpravě obvodů statistické služby okresních národních výborů, se mění takto:

Zaměstnanci státní služby statistické — okresní statistikové — se přidělují:

| Okresnímu národnímu výboru: | Pro správní okresy: |
|---|---|
| 24. Rumburk | Rumburk |
|  | Šluknov |
|  | Varnsdorf |
|  | Jablonné v Podještědí |
| 30. Hradec Králové | Hradec Králové |
|  | Jaroměř |
| 31. Dvůr Králové nad Labem | Dvůr Králové nad Labem |
|  | Trutnov |

## II.

Zemský národní výbor v Praze učiní potřebná personální opatření v dohodě se státním úřadem statistickým.

Ministr:

Nosek v. r.
