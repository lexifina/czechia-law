# Vyhláška nejvyššího úřadu cenového o cenách čerstvé zeleniny domácího původu.

866\.

VYHLÁŠKA

nejvyššího úřadu cenového

ze dne 12. května 1948

o cenách čerstvé zeleniny domácího původu.

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto:

### Čl. I.

Nejvyšší ceny níže uvedených druhů zeleniny domácího původu jakostní třídy A se stanoví takto:

| Druh zeleniny | Pěstitelské ceny od 12. května 1948 až do další úpravy | Spotřebitelské ceny od 14. května 1948 až do další úpravy |
|---|---|---|
|  | množství | Kčs | množství | Kčs |
| Kopr rychlený ve svazcích o 100 g | 1 kg svazků | 10.— | 1 kg svazků | 14.80 |
| Petržel rychlička s kořínkem | 1 kg | 18.— | 1 kg | 26.— |
| Reveň: |  |  |  |  |
| I. | velikost | 100 kg | 300.— | 1 kg | 5.— |
| II. | velikost | 100 kg | 200.— | 1 kg | 3.60 |
| Ředkvičky rychlené | 100 kusů | 5.— | 1 svazek o 10 kusech | 0.90 |
| Salát hlavkový o nejmenší |  |  |  |  |
|  | váze hlávky 120 g | 100 kusů | 180.— | 1 kus | 2.70 |
|  | Špenát | 100kg | 700.— | 1 kg | 10.60 |

### Čl. II.

Pokud tato vyhláška nestanoví jinak, platí ustanovení vyhlášky nejvyššího úřadu cenového ze dne 4. května 1948, č. 810 Ú. l. I, o cenách čerstvé zeleniny domácího původu.

### Čl. III.

Tato vyhláška nabývá účinnosti dnem 12. května 1948.
