# Vyhláška ministerstva sociální péče, kterou se doplňuje vyhláška ministra sociální péče ze dne 11. července 1947, č. 744 Ú. l. I., o úpravě pracovních a mzdových podmínek zemědělského dělnictva.

2952\.

VYHLÁŠKA

ministerstva sociální péče

ze dne 9. listopadu 1948,

kterou se doplňuje vyhláška ministra sociální péče ze dne 11. července 1947, č. 744 Ú. l. I., o úpravě pracovních a mzdových podmínek zemědělského dělnictva.

Podle § 1 vládního nařízení ze dne 21. prosince 1939, č. 330 Sb., o státním řízení mzdové politiky, se stanoví toto:

### Čl. I.

§ 9 vyhlášky č. 744/1947 Ú. l. I, upravující pracovní a mzdové podmínky zemědělského dělnictva, se doplňuje takto:

6\. Nemůže-li zaměstnavatel výjimečně poskytnouti samostatné a oddělené ubytování (odst. 1.), nýbrž jen společné, má zaměstnanec nárok na tuto náhradu;

| při 2 zaměstnancích ubytovaných v jedné místnosti, |  |
|---|---|
|  | každý Kčs 30,— měsíčně, |
| při 3 zaměstnancích ubytovaných v jedné místnosti, |  |
|  | každý Kčs 40,— měsíčně, |
| při 4 zaměstnancích ubytovaných v jedné místnosti, |  |
|  | každý Kčs 45,— měsíčně, |
| při více než 4 zaměstnancích ubytovaných |  |
|  | v jedné místnosti, každý Kčs 50.— měsíčně. |

7\. Nemůže-li zaměstnavatel výjimečně poskytnouti praní nebo zašívání prádla (odst. 1.), má zaměstnanec nárok na tuto náhradu:

| za praní prádla | Kčs 48,—, |
|---|---|
| za zašívání prádla | Kčs 52,— měsíčně. |

### Čl. II.

Tato vyhláška nabývá účinnosti dnem 1. listopadu 1948.

Ministr:

Erban v. r.
