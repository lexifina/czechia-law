# Vyhláška nejvyššího úřadu cenového, kterou se mění vyhláška o cenách jatečných koní, koňského masa, sádla, drobů a koňských uzenářských a masných výrobků.

3560\. *(účinnost od 1949-01-01)*

VYHLÁŠKA *(účinnost od 1949-01-01)*

nejvyššího úřadu cenového *(účinnost od 1949-01-01)*

ze dne 27. prosince 1948, *(účinnost od 1949-01-01)*

kterou se mění vyhláška o cenách jatečných koní, koňského masa, sádla, drobů a koňských uzenářských a masných výrobků. *(účinnost od 1949-01-01)*

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového a podle § 1 své vyhlášky z 22. prosince 1948, č. 3315 Ú. l. I, kterou se vydávají přechodné předpisy o tvoření cen po vyhlášení zákona o všeobecné dani, toto: *(účinnost od 1949-01-01)*

### Článek I. *(účinnost od 1949-01-01)*

Vyhláška nejvyššího úřadu cenového ze dne 21. června 1947, č. 657 Ú. l. I, o cenách jatečných koní, koňského masa, sádla, drobů a koňských uzenářských a masných výrobků, se mění takto: *(účinnost od 1949-01-01)*

§ 3 zní: *(účinnost od 1949-01-01)*

„Nejvyšší ceny koňského masa ve velkém včetně všeobecné daně činí v Kčs za 1 kg: *(účinnost od 1949-01-01)*

|  | 1. V půlkách: |  |
|---|---|---|
| a) | v místech I. cenové skupiny | 18.20 |
| b) | v místech II. a III. cenové skupiny | 17.25 |
| c) | v místech IV. cenové skupiny | 15.25 |
|  | 2. Ve čtvrtích: |  |
| a) | v místech I. cenové skupiny — přední | 17.05 |
|  |  | zadní | 19.— |
| b) | v místech II. III. cenové skupiny — přední | 16.25 |
|  |  | zadní | 18.20 |
| c) | v místech IV. cenové skupiny — přední | 14.10 |
|  |  | zadní | 16.05“. | *(účinnost od 1949-01-01)*

### Článek II. *(účinnost od 1949-01-01)*

Tato vyhláška nabývá účinnosti dnem 1. ledna 1949. *(účinnost od 1949-01-01)*

Za předsedu: *(účinnost od 1949-01-01)*

Dr. Domorázek v. r. *(účinnost od 1949-01-01)*
