# Vyhláška nejvyššího úřadu cenového o cenách odpadové oceli, zlomkové litiny a užité oceli.

1015\.

VYHLÁŠKA

nejvyššího úřadu cenového

ze dne 29. května 1948

o cenách odpadové oceli, zlomkové litiny a užité oceli.

Nejvyšší úřad cenový stanoví podle § 2, odstavec 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto:

### § 1.

Základní ceny stanovené touto vyhláškou platí pro dodávky spotřebitelům a rozumějí se za 1000 kg.

### § 2.

**Základní ceny odpadové oceli.**

(1) Základní ceny odpadové oceli podle ČSN normy 1441-1947 níže předepsané jakosti se stanoví takto:

|  | I. druh. Těžká odpadová ocel: |  |
|---|---|---|
| Ocelový odpad vhodný k přímému sázení do ocelářských pecí, nejmenší tloušťka stěny 6 mm, rozměry jednotlivých kusů nejvýše 1500 X 500 X 500 mm, kola mohou míti průměr nejvýše 1100 mm | Kčs 420.— |
|  | II. druh. Těžká odpadová ocel pro elektrické pece: |  |
| Ocelový odpad jednoduchého tvaru, tloušťka nejméně 6 mm, |  |
| a) rozměry jednotlivých kusů nejvýše 1000 X 300 X 300 mm | Kčs 448.— |
| b) rozměry jednotlivých kusů nejvýše 500 X 300 X 300 mm | Kčs 476.— |
|  | III. druh. Odpadová ocel pro kupolní pece: |  |
| a) Starý i nový drobný ocelový odpad, vhodný k přímému sázení do kupolních pecí tloušťka nejméně 6 mm, délka jednotlivých kusů nejvýše 400 mm (patří sem též odpad z temperované litiny), | Kčs 476.— |
| b) zvláštní druh podle přání objednavatele | Kčs 530.— |
|  | IV. druh. Střední odpadová ocel: |  |
| Ocelový odpad vhodný k přímému sázení do ocelářských pecí, tloušťka přes 3 mm; rozměry jednotlivých kusů nejvýše 1500 X 500 X 500 mm; (sem patří též drátěná lana stočená do průměru nejvýše 600 mm a odpad ocelových trubek, tloušťka stěny přes 3 mm) | Kčs 364.— |
|  | V. druh. Smíšená odpadová ocel: |  |
| Ocelové odpadky a části, které nejsou vhodné k přímému sázení do pecí, rozměry větší, než jsou předepsány pro druhy I až IV, jakož i takové, které se dají roztřídit do jednotlivých druhů I až IV po event. zvláštní mechanické úpravě (rozřezání a pod.); patří sem též drátěná lana, tloušťka přes 3 mm, stočená do průměru přes 600 mm nebo nestočená; smíšená odpadová ocel nesmí obsahovati plechy tenčí než 3 mm, ani dráty, ani drátěné pletivo | Kčs 266.— |
|  | VI. druh. Lehká odpadová ocel nová: |  |
| Volný odpad nových ocelových plechů, trubek a jiných částí, tloušťka do 3 mm | Kčs 295.— |
|  | VII. druh. Lehká odpadová ocel stará: |  |
| Volný odpad starých ocelových plechů, trubek a jiných částí, tloušťka do 3 mm | Kčs 255.— |
|  | VIII. druh. Balíky pro ocelářské pece: |  |
| Ocelový odpad upravený do balíků vhodný k sázení do pece, balíky mají obvyklé rozměry 600 X 400 X 300 mm; k tloušťce materiálu se nepříhlíží |  |
| a) balíky nového ocelového plechu, páskové oceli nebo drátu, strojně lisované | Kčs 472.— |
| b) balíky nového ocelového plechu, páskové oceli nebo drátu, ručně vázané | Kčs 364.— |
| c) balíky starých ocelových odpadků, strojně lisované | Kčs 472.— |
| d) balíky starých ocelových odpadků, ručně vázané | Kčs 364.— |
|  | IX. druh. Balíky pro vysoké pece: |  |
| Starý ocelový odpad slisovaný do balíků, balíky mají rozměry nejvýše 400 X 300 X 200 mm nebo 600 X 400 X 150 mm, balíky mohou obsahovat i odpad smaltovaný, lakovaný, nebo s kovovými a jinými povlaky, pokud to není na závadu další výrobě | Kčs 472.— |
|  | X. druh. Odpadová ocel pro vysoké pece: |  |
| Volný drobný ocelový odpad všech druhů (i s povlaky kovů, smaltu, laku a pod., pokud to není na závadu další výrobě), který se dá nabírati lopatou; patří sem také opálené ocelové části a odpadky (na př. rošty) a spálená nebo smaltovaná litina nevhodná k sázení do kupolních pecí | Kčs 308.— |
|  | XI. druh. Třísky: |  |
| a) ocelové třísky krátké, t. j. ocelové třísky, které lze nabírati lopatou | Kčs 318.— |
| b) ocelové třísky dlouhé, t. j. ocelové třísky, které se dají nakládati magnetem nebo drapákem | Kčs 240.— |
| c) ocelové třísky pálené | Kčs 318.— |
| d) litinové třísky | Kčs 318.— |
| e) ocelové třísky vlnité, t. j. ocelové třísky, které pro sázení do pece vyžadují zvláštní úpravy; mohou obsahovat i třísky uvedené pod a) až c) | Kčs 170.— |

(2) Tak zvaná smíchaná odpadová ocel stará, přimíšená k výmětové odpadové oceli se považuje za lehkou odpadovou ocel starou (druh VII).

(3) Dodává-li se odpadová ocel druhů I a IV na přání zákazníkovo v rozměrech nepřesahujících 1200 × 500 × 500 mm, je základní cena o Kčs 22.— za 1000 kg vyšší než je stanoveno v odstavci 1.

(4) Je dovoleno, aby spotřebitelé odpadové oceli a obchodníci s odpadovou ocelí sjednávali úmluvy o bližším složení druhu odpadové oceli pro kupolní pece, uvedeného jako druh IIIb.

(5) Za odpadovou ocel k vsázce nevhodnou a za smíchanou odpadovou ocel, jakož i za jiné druhy odpadové oceli, jež nemůže býti zcela nebo částečně zpracována na odpadovou ocel pro kupolní pece, dále za druhy odpadové oceli pro kupolní pece, jež neodpovídá jakostním předpisům stanoveným pro III druh, nesmějí býti jako základní ceny požadovány a poskytovány ceny stanovené pro III. druh.

(6) Ceny odpadové oceli pro kupolní pece smějí býti požadovány nebo placeny jenom při dodávkách spotřebiteli odpadové oceli, který odpadovou ocel spotřebuje v kupolní peci. Spotřebitel odpadové oceli je povinen použiti odpadové oceli pro kupolní pece výlučně v kupolní peci.

### § 3.

**Základní ceny zlomkové litiny.**

(1) Základní ceny zlomkové litiny podle ČSN normy 1119-1947 níže uvedené jakosti se stanoví takto:

|  | I. druh. Kokilová zlomková litina: |  |
|---|---|---|
| Vhodně roztlučené zlomky kokil, kokilových podložek a desek | Kčs 994.— |
|  | II. druh. Těžká strojní zlomková litina: |  |
| Vhodně roztlučené části strojů s tloušťkou stěny přes 10 mm, bez tvrdé, opálené a spálené litiny, oceli, temperované litiny a podobně; patří sem také ložisková pouzdra železničních vozů ze šedé litiny | Kčs 874.— |
|  | III. druh. Stavební a střední zlomková litina: |  |

|  | IV. druh. Lehká zlomková litina: |  |
| Zlomky kamnové a hrncové litiny, zlomky tenkostěnných trub, radiatorů a podobně, bez tvrdé, opálené a spálené litiny, oceli a podobně | Kčs 504.— |
|  | V. druh. Opálená zlomková litina: |  |
| Zlomky opálených roštů a částí topenišť, nádob z chemického průmyslu a podobně, vhodné k sázení do kupolní pece | Kčs 462.— |
| Odpadky spálené litiny patří do odpadové oceli, druh X — viz ČSN 1441-1947 Odpadová ocel. |  |
|  | VI. druh. Zvláštní zlomková litina: |  |
| Zlomky litiny zvláštního složení: |  |
| a) tvrdá zlomková litina: odlitků z tvrdé litiny, na př. tvrdých válců, bandáží, drtičů, desek a pod. |  |
|  | aa) neroztlučená do 400 mm tloušťky | Kčs 588.— |
|  | bb) neroztlučená přes 400 mm tloušťky | Kčs 388.— |
| b) tvrzená zlomková litina: zlomky odlitků povrchově tvrzených, na př. tvrzených válců, tvrzených kol, bandáží a podobně |  |
|  | aa) neroztlučená do 400 mm tloušťky | Kčs 588.— |

(2) U neroztlučené zlomkové litiny druhů I, II, III, a VI c se snižují ceny uvedené v odstavci 1 o ceny placené za roztloukání stanovené v § 7, odstavec 1.

### § 4.

**Základní ceny legované odpadové oceli a legované zlomkové litiny.**

Jako základní ceny pro legovanou odpadovou ocel a legovanou zlomkovou litinu platí základní, ceny pro nelegovanou odpadovou ocel (§ 2) a pro nelegovanou zlomkovou litinu (§ 3), zvýšené o cenové přirážky za obsah legovacích (slitinu tvořících) prvků uvedené v příloze této vyhlášky.

### § 5.

**Ceny užité oceli.**

(1) Užitou ocelí se rozumí:

Železné a ocelové výrobky všeho druhu a provedení bez ohledu na stupeň opracování, které z důvodů opotřebení nebo z jakýchkoliv jiných důvodů již pozbyly ceny nových výrobků nebo se vyskytují v rozebraných zařízeních a mohou býti použity jako náhrada nové oceli.

Jsou to zejména:

I. polotovary,

II. železniční materiál:

a) materiál pro železniční vrchní stavbu, jako na př. kolejnice železniční, žlábkové, důlní kolejnice pro polní dráhy a jiné kolejnice, železné pražce, spojky, podkladnice, svěrky, příložky, přídržné kolejnice a pod.,

b) pojezdný železniční materiál, jako na př. nápravy, materiál na kola, náboje, obruče, podvozky, hvězdice, kola a soukolí.

III. Tvarová ocel (tvarové železo), nosníky se širokými přírubami, štětovnice,

IV. tyčová ocel (tyčové železo) včetně hřídelů,

V. ocelové (železné) plechy, široká plochá ocel (universální železo) a pásková ocel (páskové železo),

VI. ocelový (železný) drát,

VII. roury, tvarovky, fitinky a příruby z litiny nebo oceli,

VIII. výkovky,

IX. jiné užité železo (též řemenice).

(2) Pro užitou ocel III., IV. a V. druhu s výjimkou hřídelů platí při prodeji spotřebiteli cena Kčs 1540.— za 1000 kg.

(3) Cena ostatních druhů užité oceli nesmí při prodeji spotřebiteli přesahovati 75% nejvýše přípustné ceny stejného nového zboží, nebo není-li stejného nového zboží 75% ceny přiměřené nejvýše přípustné ceně podobného nového zboží téhož druhu.

(4) Opracovává-li prodávající na žádost kupujícího prodávanou ocel zvláštním způsobem přesahujícím v obchodě obvyklou úpravu, smí být kromě ceny podle odstavce 2 a 3 účtována za tyto práce odměna v místě obvyklá a podle cenových předpisů přípustná.

### § 6.

**Obchodní rozpětí.**

(1) a) Pokud není touto vyhláškou stanoveno jinak, smí meziobchod prodávati odpadovou ocel nejvýše za základní ceny snížené o Kčs 20.—; místo výskytu za základní ceny snížené o Kčs 60.— za 1000 kg.

b) Zlomkovou litinu smí meziobchod prodávati nejvýše za základní ceny snížené o 5%; místo výskytu za základní ceny snížené o 15%.

(2) Základní cena stanovená pro lehkou odpadovou ocel starou VII. druh se dále snižuje, kromě snížení podle odstavce 1a), při nákupu nejméně 5000 kg od meziobchodníka o 7.50 Kčs a při nákupu z místa výskytu o 37.50 Kčs za 1000 kg.

(3) Základní cena stanovená pro lehkou odpadovou ocel starou VII. druh se dále snižuje kromě snížení podle odstavce 1 a), při dodávkách menších než 5000 kg:

a) při dodávkách povozem o Kčs 15.— za 1000 kg; tato cena se rozumí franko dvůr sběrného skladu obchodníka nebo spotřebního závodu;

b) při vagonových dodávkách o Kčs 45.— za 1000 kg; tato cena se rozumí franko vagon odesílací stanice.

(4) Při dodávkách lehké odpadové oceli VII. druh povozem se považuje množství 5000 kg za dosažené, zní-li kupní smlouva na toto množství a uskuteční-li se dodávka do 10 dnů od jejího uzavření.

(5) Dodává-li se na přání odběratele odpadová ocel se zaručeným obsahem nejvýše P 0.04%, S 0.04%, vcelku však P + S nejvýše 0.07% je přípustná přirážka Kčs 70.— za 1000 kg k cenám uvedeným v § 2 této vyhlášky.

(6) Při nákupu legované odpadové oceli a legované zlomkové litiny z míst výskytu se dále snižují, kromě snížení podle odstavce 1, základní ceny stanovené v § 4 o 27%.

(7) Pří nákupu legované odpadové oceli a legované zlomkové litiny od obchodu s odpadovou ocelí se dále snižují, kromě snížení podle odstavce 1, základní ceny stanovené v § 4 o 10%, může-li býti legovaná odpadová ocel nebo legovaná zlomková litina přidělena přímo spotřebnímu závodu, a o 17%, musí-li je převzíti na sklad odborný závod s legovanou odpadovou ocelí.

(8) Přípustné ceny za legovanou odpadovou ocel nebo legovanou zlomkovou litinu v místě výskytu jsou vyšší nejméně o Kčs 30.— za 1000 kg než ceny odpovídající nelegované odpadové oceli nebo zlomkové litiny v místech výskytu. Z toho jsou vyňaty: smíchaná legovaná odpadová ocel a smíchané legované třísky a legovaná odpadová ocel, která obsahuje legovacího kovu (přísady) méně než odpovídá hranici uvedené v příloze této vyhlášky. Za toto zboží smějí býti v místech výskytu poskytnuty nejvýše ty ceny, které jsou stanoveny pro odpovídající odpadovou ocel.

(9) Přípustné ceny legované odpadové oceli a legované zlomkové litiny při prodeji obchodem odpadovou ocelí jsou nejméně o Kčs 30.—, při prodejích odborným obchodem legovanou ocelí nejméně o Kčs 60.— za 1000 kg vyšší než ceny legované odpadové oceli nebo legované zlomkové litiny v místech výskytu, s výjimkou smíšené legované odpadové oceli, smíšených legovaných třísek a legované odpadové oceli nebo legované zlomkové litiny, obsahující méně legovacího prvku než odpovídá hranici uvedené v příloze.

(10) Při dodávce užité oceli na sklad obchodníka odpadovou ocelí se snižuje cena uvedená v § 5 o Kčs 280.— za 1000 kg.

### § 7.

**Ceny za roztloukání zlomkové litiny ve mzdě.**

(1) Za roztloukání ve mzdě zlomkové litiny nevhodné k vsázce se stanoví tyto pevné ceny:

| I. druh |  | Kčs 350.— za 1000 kg |
|---|---|---|
| II. druh |  | Kčs 300.— za 1000 kg |
| III. druh |  | Kčs 150.— za 1000 kg |
| VIa, VIb druh | do 400 mm | Kčs 400.— za 1000 kg |
|  | přes 400 mm | Kčs 600.— za 1000 kg |
| VIc. druh |  | Kčs 300.— za 1000 kg |

(2) Pokud je zadavateli na jeho výslovnou žádost dodávána zlomková litina jen v kusech do váhy nejvýše 30 kg, smějí podniky provádějící roztloukání účtovat kromě sazeb uvedených v odstavci 1. ještě přirážku nejvýše Kčs 30.— za 1000 kg.

(3) Podniky, které z příkazu Rozdělovny zřízené vyhláškou ministra průmyslu a ministra vnitřního obchodu ze dne 15. září 1947, č. 1031 Ú. l. I, o hospodaření se železným odpadem a vyhláškou ministra vnitřního obchodu a ministra průmyslu ze dne 11. března 1948, č. 438 Ú. l. I, o úpravě sběru odpadových surovin, hmot a předmětů průmyslově zužitkovatelných, v dalším jen Rozdělovna, roztloukají převzaté kokily na kusy o váze do 20 kg, smějí jako výlohy za roztloukání účtovat nejvýše Kčs 400.— za 1000 kg roztlučených kokil. Zadavatelé jsou povinni připustiti nejvýše 40% kokil roztlučených na kusy o váze 30 kg.

(4) Náklady na skládání a nakládání v místě podniku roztloukajícího litinu jsou obsaženy v uvedených sazbách. Všechny ostatní náklady spojené s dopravou litiny nese zadavatel. Podnik roztloukající litinu ve mzdě musí vrátit plné množství dodaného druhu zlomkové litiny.

### § 8.

**Dovozné, dopravní výlohy a výlohy na nakládání.**

(1) Ceny za odpadovou ocel, zlomkovou litinu, legovanou odpadovou ocel, legovanou zlomkovou litinu a užitou ocel, platí:

a) pří dopravě drahou:

franko vagon tarifní stanice místa výskytu, po případě skladu prodávajícího, při naložení nejméně 15.000 kg; při lehké odpadové oceli staré (VII. druh) nejméně 8000 kg; při vlnitých ocelových třískách (XIa druh) nejméně 6000 kg; při zlomkové litině nejméně 5000 kg, v jednom voze. Případný rozdíl dovozného za neúplně naložené vagony, s výjimkou legované odpadové oceli a legované zlomkové litiny, hradí prodávající, pokud neprokáže, že byl ložný prostor plně využit.

b) Při dopravě vozidlem odesilatele, po případě prodávajícího: franko dvůr příjemcův, bez složení. Je-li však příjemce mimo místo odeslání, nahradí příjemce odesilateli, po případě prodávajícímu částku odpovídající železničnímu dovoznému za přepravu celého dodaného množství zboží ze železniční tarifní stanice místa odeslání do železniční tarifní stanice příjemce, avšak nejméně Kčs 45.— za 1000 kg. Ustanovení předchozí věty platí obdobně, je-li příjemce v místě odeslání, které má více než jednu tarifní stanici a přesahuje-li vzdálenost skladu, v němž je zboží, ode dvora příjemce po nejkratší spojové cestě 5 km; pro výpočet náhrady je rozhodnou železniční tarifní stanice nejbližší skladu, v němž je zboží a železniční tarifní stanice nejbližší dvoru příjemce.

(2) Je zakázáno dodávati za jiných podmínek než uvedeno v odstavci 1.

(3) Převezme-li obchodník odpadovou ocelí nebo spotřebitel odpadové oceli k nakládání nebo odvozu odpadovou ocel, zlomkovou litinu, legovanou odpadovou ocel, legovanou zlomkovou litinu a užitou ocel ze skladu místa výskytu, snižují se přípustné ceny o výlohy spojené s naložením a odvozem, nejméně však o 30 Kčs za 1000 kg za nakládání a o Kčs 45.— na 1000 kg za odvoz.

### § 9.

**Prémiové přirážky.**

### § 10.

**Všeobecná cenová ustanovení.**

(1) Stanovené ceny se rozumějí včetně daně z obratu.

(2) Ceny lehké odpadové oceli staré (§ 2, odstavec 1, VII. druh) a balíků pro ocelářské a vysoké pece (§ 2, odstavec 1, VIIIa, c, a IX. druh), s výjimkou cen při nákupu z míst výskytu a ceny za roztloukání zlomkové litiny ve mzdě (§ 7, odst. 1) jsou pevné.

(3) Ostatní ceny stanovené touto vyhláškou jsou cenami nejvyššími.

### § 11.

Nejvyšší úřad cenový může povolit nebo nařídit výjimku z ustanovení této vyhlášky.

### § 12.

Přestupky této vyhlášky se trestají podle části čtvrté vládního nařízení o zřízení nejvyššího úřadu cenového a podle předpisů toto nařízení měnících nebo doplňujících.

### § 13.

(1) Tato vyhláška nabývá účinnosti dnem 1. června 1948.
