# Vyhláška československého monopolu lihového o změně prodejních cen lihu.

1176\.

VYHLÁŠKA

československého monopolu lihového

ze dne 17. června 1948

o změně prodejních cen lihu.

Československý monopol lihový stanoví podle § 98 zákona ze dne 19. února 1946, č. 30 Sb., o nové úpravě československého práva v oboru nepřímých daní a státních finančních monopolů se souhlasem nejvyššího úřadu cenového toto:

### Čl. 1.

Vyhláška československého monopolu lihového ze dne 17. září 1947, č. 973 Ú. l. I a č. 711 Ú. v., o prodejních cenách lihu se mění takto:

Ustanovení § 1 se nahrazuje tímto zněním:

Plná prodejní cena čistého lihu k výrobě lihovin, trestí, léčiv, voňavek a pod.:

|  |  |  | Maloprodej: |  |  |
|---|---|---|---|---|---|
|  |  | 1 l | prostor | Kčs | 310.— | } | za prostorový litr 95 obj. % z dodacího místa |
| přes | 1 l | do 5 l | prostor | Kčs | 305.50 |
| přes | 5 l | do 10 l | prostor | Kčs | 302.50 |
| přes | 10 l | do 25 l | prostor | Kčs | 301.50 |
| od | 25 l | do 50 l | alkoholu | Kčs | 309.— | } | za litr alkoholu z dodacího místa |
| přes | 50 l | do 100 l | alkoholu | Kčs | 307.— |
| přes | 100 l | do 150 l | alkoholu | Kčs | 306.50 |
| přes | 150 l | do 280 l | alkoholu | Kčs | 306.— |
|  |  |  | Velkoprodej: |  |  |
| přes | 280 l |  | alkoholu | Kčs | 300.— | { | za litr alkoholu vyplaceně do stanice příjemce. |

Přirážka za bezvodý líh, pokud se dodává k shora uvedeným účelům, Kčs 0.50 za litr alkoholu.

### Čl. 2.

Tato vyhláška nabývá účinnosti dnem 23. června 1948.
