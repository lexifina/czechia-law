# Vyhláška ministra vnitra o úpravě obvodů státní služby stavebnětechnické, strojnětechnické a vodohospodářské v zemi Moravskoslezské.

100\.

VYHLÁŠKA

ministra vnitra

ze dne 16. ledna 1948

o úpravě obvodů státní služby stavebnětechnické, strojnětechnické a vodohospodářské v zemi Moravskoslezské.

Podle vládního nařízení ze dne 6. března 1936, č. 51 Sb., o organisaci policejní správy a služby a o některých jiných opatřeních v oboru vnitřní správy, stanovím v dohodě s ministrem techniky toto:

## I.

**Služba stavebnětechnická.**

Zaměstnanci služby stavební, určení pro obstarávání záležitostí stavebnětechnických, se přidělují takto:

| Okresnímu národnímu výboru v: | Pro správní okresy: |
|---|---|
| 1. | Brně-venkově | Brno-venkov, Hustopeče, Mikulov, Tišnov, Vyškov; |
| 2. | Boskovicích | Boskovice, Moravská Třebová; |
| 3. | Jihlavě | Dačice, Jihlava; |
| 4. | Třebíči | Velké Meziříčí, Třebíč; |
| 5. | Novém Městě na Moravě | Nové Město na Moravě; |
| 6. | Olomouci-venkově | Moravský Beroun, Litovel, Olomouc-venkov, Prostějov, Šternberk; |
| 7. | Šumperku | Rýmařov, Šumperk, Zábřeh; |
| 8. | Přerově | Holešov, Hranice, Kroměříž, Přerov; |
| 9. | Uherském Hradišti | Uherský Brod, Hodonín, Uherské Hradiště, Kyjov, Zlín; |
| 10. | Valašském Meziříčí | Valašské Meziříčí, Vsetín; |
| 11. | Znojmě | Moravské Budějovice, Moravský Krumlov, Znojmo; |
| 12. | Opavě-venkově | Bílovec, Bruntál, Hlučín, Jeseník, Krnov, Opava-venkov; |
| 13. | Místku | Fryštát, Nový Jičín, Místek, Český Těšín. |

## II.

**Služba strojnětechnická.**

Zaměstnanci služby stavební, určení pro obstarávání záležitostí strojnětechnických, se přidělují takto:

| Okresnímu národnímu výboru v: | Pro správní okresy (statutární město): |
|---|---|
| 1. | Brně-venkově | Boskovice, Brno venkov, Hustopeče, Nové Město na Moravě, Mikulov, Tišnov, Moravská Třebová, Vyškov; |
| 2. | Jihlavě | Moravské Budějovice, Dačice, Jihlava, Moravský Krumlov, Velké Meziříčí, Třebíč, Znojmo; |
| 3. | Olomouci-venkově | Moravský Beroun, Litovel, Olomouc-venkov, Prostějov, Rýmařov, Šternberk, Šumperk, Zábřeh; |
| 4. | Uherském Hradišti | Uherský Brod, Hodonín, Holešov, Uherské Hradiště, Kroměříž, Kyjov, Přerov, Zlín; |
| 5. | Valašském Meziříčí | Hranice, Valašské Meziříčí, Vsetín; |
| 6. | Opavě-venkově | Bílovec, Bruntál, Hlučín, Jeseník, Krnov, Opava-město, Opava-venkov; |
| 7. | Místku | Fryštát, Nový Jičín, Místek, Český Těšín. |

## III.

**Služba vodohospodářská.**

Zaměstnanci zemědělskotechnické služby, určení pro obstarávání záležitostí vodohospodářských, se přidělují takto:

| Okresnímu národnímu výboru v: | Pro správní okresy (statutární města): |
|---|---|
| 1. | Brně-venkově | Boskovice, Brno-město, Brno- venkov, Hustopeče, Nové Město na Moravě, Mikulov, Tišnov, Moravská Třebová, Vyškov; |
| 2. | Jihlavě | Dačice, Jihlava, Velké Meziříčí, Třebíč; |
| 3. | Olomouci-venkově | Moravský Beroun, Litovel, Olomouc-město, Olomouc-venkov, Prostějov, Rýmařov, Šternberk, Šumperk, Zábřeh; |
| 4. | Přerově | Holešov, Hranice, Kroměříž, Valašské Meziříčí, Přerov, Vsetín; |
| 6. | Uherském Hradišti | Uherský Brod, Hodonín, Uherské Hradiště, Kyjov, Zlín; |
| 6. | Znojmě | Moravské Budějovice, Moravský Krumlov, Znojmo; |
| 7. | Opavě-venkově | Bruntál, Hlučín, Jeseník, Krnov, Opava-město, Opava-venkov; |
| 8. | Místku | Bílovec, Fryštát, Nový Jičín, Místek, Ostrava, Český Těšín. |

## IV.

**Derogace.**

Tímto opatřením pozbývají účinnosti tyto výnosy ministerstva vnitra: výnos ze dne 15. srpna 1941, č. B-2146-4/8-41-2, výnos ze dne 10. října 1944, č. B-2146-8/9-44-II (Věst. min. vn. 1944, str. 261) ve znění výnosu ze dne 19. dubna 1945, č. B-2146-15/3-45-I 1, výnos ze dne 28. června 1943, č. B-2148-20/10-42-I 1, jakož i všechna jiná opatření, pokud se týkala úpravy obvodů těchto služeb v zemi Moravskoslezské.

Za ministra:
