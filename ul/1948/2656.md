# Vyhláška nejvyššího úřadu cenového, kterou se doplňuje vyhláška nejvyššího úřadu cenového ze dne 3. července 1946 o nejvýše přípustných procentních přirážkách v obchodu s textilním zbožím.

2656\.

VYHLÁŠKA

nejvyššího úřadu cenového

ze dne 4. listopadu 1948,

kterou se doplňuje vyhláška nejvyššího úřadu cenového ze dne 3. července 1946 o nejvýše přípustných procentních přirážkách v obchodu s textilním zbožím.

Nejvyšší úřad cenový stanoví podle § 2, odst. 1 vládního nařízení o zřízení nejvyššího úřadu cenového toto:

### Čl. I.

Vyhláška nejvyššího úřadu cenového ze dne 3. července 1946, č. 1533 Ú. l. I, o nejvýše přípustných procentních přirážkách v obchodu s textilním zbožím, ve znění vyhlášky ze dne 24. března 1947, č. 351 Ú. l. I a vyhlášky ze dne 25. dubna 1947, č. 431 Ú. l. I, se doplňuje takto:

V § 1, odst. 5 se připojuje toto další ustanovení:

„Hromadnou dodávkou se rozumí dodávka, jejíž hodnota, vypočtená podle odst. 1 a 2, činí nejméně

| a) | u zboží skupiny A přílohy vyhlášky | Kčs 15.000.—, |
|---|---|---|
| b) | u zboží skupiny B přílohy vyhlášky | Kčs 8.000.—, |
| c) | u zboží skupiny C přílohy vyhlášky | Kčs 10.000.—, |
| d) | u zboží skupiny G přílohy vyhlášky | Kčs 25.000.—, |
| e) | u zboží skupiny H přílohy vyhlášky |  |
|  | při nákupní ceně do Kčs 50.— | Kčs 4.000.—, |
|  | při nákupní ceně do Kčs 100.— | Kčs 8.000.—, |
|  | při nákupní ceně nad Kčs 100.— | Kčs 10.000.—, |
| f) | u ostatního zboží | Kčs 5.000.—, |
| g) | u dodávek, obsahujících různé druhy zboží, které jednotlivě nedosahují částek stanovených sub a)—f) | Kčs 10.000.—.“ |

### Čl. II.

Tato vyhláška nabývá účinnosti třetím dnem po vyhlášení.

Za předsedu:

Dr. Maur v. r.
