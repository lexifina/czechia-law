# Vyhláška nejvyššího úřadu cenového o cenách raných jedlých bramborů domácího původu ze sklizně 1945.

166\.

Vyhláška

nejvyššího úřadu cenového

ze dne 17. srpna 1945,

o cenách raných jedlých bramborů domácího původu ze sklizně 1945.

Nejvyšší úřad cenový stanoví:

### Článek I.

Vyhláška nejvyššího úřadu cenového ze dne 27. června 1945, běž č. 58, o cenách raných jedlých bramborů domácího původu ze sklizně 1945 (Úř. I. č. 37/1945), ve znění vyhlášky ze dne 24. července 1945, běž. č. 108 (Úř. I. č. 58/1945), se doplňuje a mění takto:

1\. § 1, odst. 1 zní:

„(1) Pevné ceny raných jedlých bramborů domácího původu ze sklizně 1945 při prodeji pěstitelem výkupnímu rozdělovači činí beze srážek podle § 2:

| při dodávce v době: | standard I., II., a III. (t. j. žlutomasé: podlouhlé, rohlíčky a modroočky) | standard IV. (t. j. žlutomasé kulaté) | standard V (t. j. bělomasé) |
|---|---|---|---|
|  | K | K | K |
| od 23. srpna do 31. srpna | 100.— | 80.—, | 70.—.“ |

2\. § 4 zní:

### „§ 4

Ceny při prodeji výkupním rozdělovačem prodejnímu rozdělovači.

Výkupní rozdělovač si smí při prodeji prodejnímu rozdělovači zaúčtovat k cenám podle § 1 nejvyšší obchodní rozpětí K 5.— za 150 kg čisté váhy.“

3\. § 5, odst. 1, písm. a) a b) zní:

|  |  | K |
|---|---|---|
| „a) | při dodávce franko prodejna maloobchodníku nebo franko sklep velkospotřebitele | 14.—, |
| b) | při sjednaném vlastním odvezení maloobchodníkem anebo velkospotřebitelem z vagonu (člunu) anebo ze skladu prodejního rozdělovače | 8.—.“ |

4\. § 6, odst. 1, věta první zní:

„Maloobchodník si smí při prodeji spotřebiteli účtovat k cenám přípustným podle § 5, odst. 1, písm. a) a § 7, odst. 1, A., písm. a), bb), (t. j. k cenám bez náhrady účtované za obaly), tato nejvyšší obchodní rozpětí:

|  |  | K |
|---|---|---|
| a) | při prodeji pod 50 kg | 0.35, |
| b) | při prodeji 50 kg a více | 0.15 |

na 1 kg.“

5\. § 7, odst. 1, A. a B. zní:

„A. Při prodeji výkupním rozdělovačem přímo:

| a) maloobchodníku nebo velkospotřebiteli | K |
|---|---|
|  | aa) | ze skladu výkupního rozdělovače | 5.—, |
|  | bb) | franko prodejna maloobchodníka nebo franko sklep velkospotřebitele | 11.—; |
| b) spotřebiteli |  |
|  | aa) | ze skladu výkupního rozdělovače |  |
|  |  | při dodávce 50 kg a více | 13.—, |
|  |  | při dodávce méně než 50 kg | 21.—; |
|  | bb) | franko sklep spotřebitele |  |
|  |  | při dodávce 50 kg a více | 19.—, |
|  |  | při dodávce méně než 50 kg | 27.—. |

B. Při prodeji prodejním rozdělovačem přímo spotřebiteli:

| a) | ze skladu prodejního rozdělovače | K |
|---|---|---|
|  | při dodávce 50 kg a více | 16.—, |

### Článek II.

Tato vyhláška nabývá účinnosti dne 23. srpna 1945.
