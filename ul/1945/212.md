# Vyhláška nejvyššího úřadu cenového o cenách zeleniny a ovoce domácího původu, kterou se pozměňuje vyhláška nejvyššího úřadu cenového ze dne 25. srpna 1945, o cenách ovoce a zeleniny domácího původu, uveřejněná v Úředním listě č. 86 ze dne 29. srpna 1945.

212\.

Vyhláška

nejvyššího úřadu cenového

ze dne 5. září 1945

o cenách zeleniny a ovoce domácího původu, kterou se pozměňuje vyhláška nejvyššího úřadu cenového ze dne 25. srpna 1945, o cenách ovoce a zeleniny domácího původu, uveřejněná v Úředním listě č. 86 ze dne 29. srpna 1945.

### Čl. I.

Vyhláška nejvyššího úřadu cenového ze dne 25. srpna 1945 pozměňuje se takto:

a) v § 1:

|  | pěstitelské ceny | maloobchodní nejvyšší prodejní ceny |
|---|---|---|
|  | množství | I | II |
| K |  | K | K |
| Švestky, renklody, mirabelky a slívy za 100 kg | 600.— | 1 kg | 8.80 | 9.20 |
| Hrušky |  |  |  |  |
| Jablka |  |  |  |  |

Švestky místo označení velikost označení cenová skupina I., II., III.

### Čl. II.

Tato vyhláška vstupuje v platnost dnem vyhlášení.

Za předsedu nejvyššího úřadu cenového:

Dr. Maur v. r.
