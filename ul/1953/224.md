# Vyhláška ministerstva zemědělství o cenách ovoce a semen z vybraných matečných semenných stromů.

224\. *(účinnost od 1953-07-22)*

VYHLÁŠKA *(účinnost od 1953-07-22)*

ministerstva zemědělství *(účinnost od 1953-07-22)*

ze dne 11. července 1953 *(účinnost od 1953-07-22)*

o cenách ovoce a semen z vybraných matečných semenných stromů. *(účinnost od 1953-07-22)*

Ministerstvo zemědělství vyhlašuje y dohodě se zúčastněnými ústředními úřady podle § 1 odst. 3 zákona č. 80/1948 Sb., kterým se ministr zemědělství zmocňuje k opatřením v zemědělské výrobě, a podle § 7 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen: *(účinnost od 1953-07-22)*

(1) Výkupní ceny ovoce a semen z vybraných matečných semenných stromů činí za 1 kg *(účinnost od 1953-07-22)*

|---|---|---|
|  | jablka planá na semeno | Kčs 0,90 |

(2) Výkupní ceny jsou pevné a rozumějí se franko nakládací stanice pěstitele a bez obalů. *(účinnost od 1953-07-22)*

### § 2. *(účinnost od 1953-07-22)*

(1) Maloobchodní ceny ovoce a semen z vybraných matečných semenných stromů činí za 1 kg *(účinnost od 1953-07-22)*

| a) | ovoce: |  |
|---|---|---|
|  | ořechy čerstvé bez rubiny | Kčs 25,— |
|  | ořechy suché | Kčs 30,— |
|  | ořechy čerstvé elitní výběr bez rubiny | Kčs 45,— |
|  | mandle bez rubiny | Kčs 23,— |
| b) | jader: |  |
|  | z planých jabloní | Kčs 120,— |
|  | z jabloní ušlechtilých odrůd | Kčs 250,— |
|  | z planých hrušní | Kčs 160,— |
|  | z hrušní ušlechtilých odrůd | Kčs 250,— |
| c) | pecek: |  |
|  | z broskví | Kčs 3,60 |
|  | z meruněk | Kčs 3,— |
|  | z mahalebek | Kčs 36,— |
|  | z třešní ptačích | Kčs 25,— |
|  | z višní | Kčs 25,— |
|  | z myrabolány | Kčs 21,— |
|  | z červené slivky (vörös szilva) | Kčs 22,— |
|  | ze žlutého špendlíku, biele slivky | Kčs 15,— |
|  | z okrouhliček a kulovaček | Kčs 22,— |
|  | z durancií | Kčs 15,— |
|  | z výběrových odrůd, jako Wagenhiemova švestka, zelená renklota, Čachtická slíva a podobně | Kčs 27,— | *(účinnost od 1953-07-22)*

(2) Maloobchodní ceny jsou pevné a rozumějí se za čistou váhu, bez obalů, včetně daně z obratu, loko sklad prodávajícího. *(účinnost od 1953-07-22)*

### § 3. *(účinnost od 1953-07-22)*

Ceny uvedené v §§ 1 a 2 platí pouze pro ovoce a semena ze stromů zvlášť vybraných k seťovým účelům Výzkumným ústavem ovocnářským nebo orgány jím pověřenými. *(účinnost od 1953-07-22)*

### § 4. *(účinnost od 1953-07-22)*

Tato vyhláška nabývá účinnosti dnem 22. července 1953. *(účinnost od 1953-07-22)*
