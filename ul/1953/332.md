# Vyhláška úřadu pro normalisaci, kterou se vyhlašují technické státní normy pro některé potravinářské výrobky.

332\.

VYHLÁŠKA

úřadu pro normalisaci

ze dne 8. října 1953,

kterou se vyhlašují technické státní normy pro některé potravinářské výrobky.

Úřad pro normalisaci vyhlašuje podle § 8 vládního nařízení č. 45/1951 Sb., o technické normalisaci:

### § 1.

<sup>*</sup> (1) Technickými státními normami od 1. října 1953 jsou normy:

| ČSN 56 8151 | „Zmrazené třešně“ |
| ČSN 56 8152 | „Zmrazený rybíz“ |
| ČSN 56 8153 | „Zmrazené meruňky“ |
| ČSN 56 8154 | „Zmrazené jahody“ |
| ČSN 56 8155 | „Zmrazené borůvky“ |
| ČSN 56 8156 | „Zmrazené švestky“ |
| ČSN 56 8310 | „Zmrazený malinový protlak“ |
| ČSN 56 9140 | „Zmrazené paprikové lusky“ |
| ČSN 56 9142 | „Zmrazené okurky a zmrazený okurkový salát“ |

| ČSN 56 9145 | „Zmrazená rajská jablka“ |

(2) Jde o normy jakosti, které vytyčují zejména hlavní znaky technologického postupu, jednají o surovinách, balení, označování, dopravě a skladování předmětů, jichž se týkají.
