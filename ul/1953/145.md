# Vyhláška státního úřadu plánovacího, kterou se vyhlašují změny technických státních norem, vyhlášených pro některé potravinářské výrobky, vyhláškami č. 92 a 93/1952 Ú. l.

145\.

VYHLÁŠKA

státního úřadu plánovacího

ze dne 17. dubna 1953,

kterou se vyhlašují změny technických státních norem, vyhlášených pro některé potravinářské výrobky, vyhláškami č. 92 a 93/1952 Ú. l.

Státní úřad plánovací vyhlašuje podle § 8 vládního nařízení č. 45/1951 Sb., o technické normalisaci:

### § 1.

Dnem uveřejnění této vyhlášky se mění normy:

| ČSN 56 7850 | Kvasný ocet |
|---|---|
|  | V článku 4. Methody kontroly jakosti se vkládá na konec ustanovení, které se týká obsahu kyseliny octové, nový odstavec tohoto znění: |
|  | „Při chemickém stanovení obsahu kyseliny octové a kvasného octa lihového pro průmyslové zpracováni a u jakostního kvasného octa lihového se připouští odchylka ± 0,1%.” |
| ČSN 56 8720 | Kompoty |
|  | Na straně 3, písmeno J. Hrušky celé (kompot) se vkládá nový odstavec: |
|  | „III. jakost obsahuje hrušky půlené, po případě čtvrcené, neloupané, bez kalichů, stopek a jadřinců, chuti hruškové, struktury pevné; nepatrné otlačeniny jsou přípustné.” |
| ČSN 57 6099 | Společná ustanovení norem jakosti pro masné výrobky. |
|  | V ustanovení 1. (třídění masa) se v písmeně b) vypouští na konci tato slova: |
|  | „Hm III sekánka, vyrobená z hovězího masa H III bez přidání vody (Štes).” V témže ustanovení písmeno c) V I zní takto: „V I převážně libový výřez bez kůže a části masa bez blan a šlach, syrový, zmrazený i solený.” |
| ČSN 57 7751 | Játrová paštika — konserva. |
|  | V ustanovení I. Suroviny na 1 t. výrobku: se před slova „tuk morkový .. 20 kg” vloží „spařené škvarky .. 50 kg.” |
| ČSN 58 0919 | Sůl jedlá a krmná. |
|  | Strana 1., v definici se vypouští tato slova: „ .... jakož i sůl, která odpadá jako vedlejší produkt v chemickém průmyslu (t. zv. sůl konvertní).“ |

Za ministra-předsedu státního úřadu plánovacího:

Dr. Vlasák v. r.
