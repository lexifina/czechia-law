# Vyhláška státního úřadu plánovacího, kterou se vyhlašují technické státní normy pro součásti zemědělských strojů, pro čepy s půlkulovou hlavou pro závěsy, pro zkoušení kovů, pro průvlaky ze slinutých karbidů, pro trolejový drát, pro uskladnění a ošetřování výrobků z pryže, pro objemovou jednotku, přírodních a uměle vyráběných plynů, pro trojúhelníky dřevěné školní, pro pomůcky k rýsování, pro pečetní vosky, pro protipožární zařízení, pro obsluhu vodních turbin, pro nátěrové hmoty, pro mazací tuky, pro zkoušky tuhých nekovových materiálů, pro měděné holé dráty a pásy pro vodiče a kabely.

202\.

VYHLÁŠKA

státního úřadu plánovacího

ze dne 25. dubna 1953,

kterou se vyhlašují technické státní normy pro součásti zemědělských strojů, pro čepy s půlkulovou hlavou pro závěsy, pro zkoušení kovů, pro průvlaky ze slinutých karbidů, pro trolejový drát, pro uskladnění a ošetřování výrobků z pryže, pro objemovou jednotku přírodních a uměle vyráběných plynů, pro trojúhelníky dřevěné školní, pro pomůcky k rýsování, pro pečetní vosky, pro protipožární zařízení, pro obsluhu vodních turbin, pro nátěrové hmoty, pro mazací tuky, pro zkoušky tuhých nekovových materiálů, pro měděné holé dráty a pásy pro vodiče a kabely.
