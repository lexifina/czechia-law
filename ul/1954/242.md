# Vyhláška ministra školství, kterou se mění vyhláška ministra vysokých škol č. 248/1953 Ú. l., o označení absolventů vysokých škol.

242\.

ze dne 10. prosince 1954.

kterou se mění vyhláška ministra vysokých škol č. 248/1953 Ú. l., o označení absolventů vysokých škol.

Čl. I oddíl II č. 9 vyhlášky č. 248/1953 Ú. l. se mění a zní:

| 9. chemie | a) inženýrská chemie |  |
|  | b) anorganická technologie |  |
|  | c) organická technologie | inženýr chemie”. |
|  | d) chemická technologie paliv |  |
|  | e) potravinářská technologie |  |
