# Vyhláška státního úřadu plánovacího, kterou se vyhlašují technické státní normy pro zednické nářadí, kompensaci jalového proudu statickými kondensátory, typisaci parních elektráren, tvrzený papír a tvrzené tkaniny.

258\.

VYHLÁŠKA

státního úřadu plánovacího

ze dne 5. září 1952,

kterou se vyhlašují technické státní normy pro zednické nářadí, kompensaci jalového proudu statickými kondensátory, typisaci parních elektráren, tvrzený papír a tvrzené tkaniny.

Státní úřad plánovací vyhlašuje podle § 8 vládního nařízení č. 45/1951 Sb., o technické normalisaci:

(2) Normy pojednávají o jednotlivých druzích zednického nářadí a stanoví jejich rozměry a jakosti.

### § 2.

(1) Norma ČSN 38 0710 „Kompensace jalového proudu statickými kondensátory” jest od 1. října 1952 technickou státní normou; tato norma je směrná.

(2) Norma platí pro kompensaci jalového proudu statickými kondensátory a mimo jiné obsahuje zejména předpisy pro provádění jednotlivých druhů kompensace.

### § 3.

(1) Norma ČSN 38 1110 „Typisace parních elektráren 100 a 200 MW” je od 1. října 1952 technickou státní normou; tato norma je směrná.

(2) Tato norma platí pro velké parní elektrárny a směřuje k jednotnosti a zjednodušení jejich výstavby. Vytyčuje zejména základní předpoklady, zásady a technické požadavky pro projekty, stavby a provoz parních elektráren.

### § 4.

(1) Technickými státními normami jsou od 1. ledna 1953 normy:

|---|---|
| ČSN 64 4201 | „Tvrzený papír” |

| ČSN 64 4221 | „Trubky vinuté z tvrzeného papíru” |
| ČSN 64 4223 | „Čtyřhranné trubky ostrohranné z tvrzeného papíru” |
| ČSN 64 4224 | „Tyče z tvrzeného papíru” |
| ČSN 64 4301 | „Tvrzené tkaniny” |
| ČSN 64 4310 | „Desky z tvrzené tkaniny” |
| ČSN 64 4321 | „Trubky vinuté z tvrzené tkaniny” |
| ČSN 64 4324 | „Tyče z tvrzené tkaniny”. |

(2) Normy jednají o tvrzeném papíru a tvrzených tkaninách.

Norma ČSN 64 4001 jako norma základní třídí tvrzený papír a tvrzené tkaniny a popisuje způsob přejímání a dodávání včetně zkušebních method.

Norma ČSN 64 4201 a ČSN 64 4301 jsou normy jakostní. Ostatní normy jsou rozměrové normy polotovarů.
