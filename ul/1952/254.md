# Vyhláška úřadu pro normalisaci, kterou se vyhlašují technické podmínky pro výrobky těžkého strojírenství

254\.

VYHLÁŠKA

úřadu pro normalisaci

ze dne 19. srpna 1952,

kterou se vyhlašují technické podmínky pro výrobky těžkého strojírenství
