# Vyhláška státního úřadu plánovacího, kterou se vyhlašují technické státní normy pro klíče.

110\.

VYHLÁŠKA

státního úřadu plánovacího

ze dne 9. dubna 1952,

kterou se vyhlašují technické státní normy pro klíče.

Státní úřad plánovací vyhlašuje podle § 2 vládního nařízení č. 45/1951 Sb. o technické normalisaci:

### § 1.

Technickými státními normami jsou od 1. srpna 1952 normy:

| ČSN 23 0600 | Klíče — Přehled |
|---|---|
| ČSN 23 0601 | Klíče — Jakostní podmínky otevřených klíčů |
| ČSN 23 0603 | Otvory klíčů |
| ČSN 23 0604 | Otvory klíčů — Mezní úchylky |
| ČSN 23 0605 | Prostor potřebný po užití klíčů na šestihrany |
| ČSN 23 0607 | Otvory klíčů — Přiřadění klíčů k šroubům a maticím |
| ČSN 23 0609 | Klíče — Hlavy otevřených klíčů |
| ČSN 23 0610 | Otevřené klíče oboustranné |
| ČSN 23 0611 | Zvláštní otevřené klíče oboustranné |
| ČSN 23 0625 | Otevřené klíče |
| ČSN 23 0626 | Zvláštní otevřené klíče |
| ČSN 23 0628 | Otevřené klíče — s krátkou rukojetí |
| ČSN 23 0630 | Zavřené klíče na šestihrany |
| ČSN 23 0633 | Zavřené klíče na čtyřhrany |
| ČSN 23 0650 | Nástrčné klíče nástavné |
| ČSN 23 0651 | Trubkové klíče šestihranné |
| ČSN 23 0653 | Trubkové klíče oboustranné |
| ČSN 23 0659 | Rukojeti ke klíčům a šroubovákům |
| ČSN 23 0670 | Zástrčné klíče ohnuté |
| ČSN 23 0681 | Zástrčné klíče na čtyřhrany |
| ČSN 23 0710 | Zástrčné klíče šestihranné |
| ČSN 23 0750 | Zatahováky na závrtné šrouby. |

### § 2.

Norma ČSN 23 0600 podává přehled o všech normách, vydaných až dosud pro klíče a jednotlivé, elementy klíčů.

Norma ČSN 23 0605 stanoví prostor potřebný při používání klíčů, norma ČSN 23 0607 obsahuje údaje pro přiřadění klíčů k šroubům a maticím, ostatní normy pak obsahují základní, zejména rozměrové údaje pro jednotlivé klíče a elementy klíčů.

Za ministra-předsedu státního úřadu plánovacího:

Dr. Vlasák v. r.
