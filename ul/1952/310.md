# Vyhláška státního úřadu plánovacího, kterou se vyhlašují za technické státní normy úsekové normy ministerstva potravinářského průmyslu pro některé výrobky potravinářské.

310\.

VYHLÁŠKA

státního úřadu plánovacího

ze dne 4. října 1952,

kterou se vyhlašuji za technické státní normy úsekové normy ministerstva potravinářského průmyslu pro některé výrobky potravinářské.

Státní úřad plánovací vyhlašuje podle § 8 vládního nařízení č. 45/1951 Sb., o technické normalisaci:

### § 1

Technickými státními normami jsou od 1. listopadu 1952 tyto normy:

|  |  | dříve úseková norma |
|---|---|---|
| ČSN 0519 | Mlýnské výrobky z obili | Ú 51 |
| ČSN 56 6674 | Sladová moučka | Ú 51 |
| ČSN 56 7810 | Ovocné vlno | Ú 51 |
| ČSN 56 8509 | Ovocná šťáva nezkvašená | Ú 51 |
| ČSN 56 9710 | Silice | Ú 51 |
| ČSN 57 2109 | Vejce čerstvá, chladírenská a konservovaná (platí jen pro vejce slepičí) | Ú 51 |
| ČSN 58 0250 | Margarin | Ú 51 |
| ČSN 66 0810 | Surový líh bramborový | Ú 51 |
| ČSN 66 0811 | Surový líh řepný | Ú 51 |
| ČSN 66 0812 | Surový líh melasový lihovarský | Ú 51 |
| ČSN 66 0813 | Surový líh obilní | Ú 51 |
| ČSN 66 0814 | Surový líh drožďárenský | Ú 51 |
| ČSN 66 0820 | Surový líh sulfitový | Ú 51 |
| ČSN 66 0825 | Rafinovaný (čištěný) líh | Ú 51 |
| ČSN 66 0835 | Dehydrovaný (bezvodý) líh | Ú 51 |
| ČSN 66 0860 | Denaturovaný líh | Ú 51 |
| ČSN 66 0370 | Přiboudlina | Ú 51 |

### § 2.

Normy obsahují definice výrobků, pro které jsou vyhlášeny, údaje o znacích jakosti, o methodě kontroly jakosti, o hlavních znacích technologického postupu, o obalech, dopravě, skladování a jiné údaje důležité pro jednotlivé výrobky.

### § 3.

Normy uvedené v § 1 jsou uveřejněny ve sbírce „Soubor norem jakosti pro výrobky potravinářského průmyslu”, vydané Průmyslovým vydavatelstvím v Praze.

Za ministra-předsedu státního úřadu plánovacího:

Dr. Vlasák v. r.
