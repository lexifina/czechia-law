# Vyhláška ministerstva vnitřního obchodu o dodávkových podmínkách, jakostních normách, výkupních cenách ovčí vlny a o výdeji bodů „OV“.

78\.

VYHLÁŠKA

ministerstva vnitřního obchodu

ze dne 1. dubna 1952

o dodávkových podmínkách, jakostních normách, výkupních cenách ovčí vlny a o výdeji bodů „OV“.

Ministerstvo vnitřního obchodu stanoví v dohodě se státním úřadem plánovacím a ministerstvy zemědělství, lehkého průmyslu a financí podle § 1 dekretu č. 118/1945 Sb., o opatřeních v řízení vyživovacího hospodářství, ve znění zákona č. 274/1948 Sb., a podle § 7 vládního nařízení č. 235/1949 Sb., o plánování a jiné tvorbě cen;

**Dodávkové podmínky.**

### § 11.

(1) Pro jednotlivé jakostní skupiny se stanoví tyto ceny:

Jakostní skupina I

| a) | vlna v rounech: |  |
|---|---|---|
|  | třída I/1 | Kčs 200,— |
|  | třída I/2 | Kčs 182,— |

Poznámka: Pro rouna, u nichž délka vlákna nedosahuje 55 mm (zejména z druhé roční stříže), platí ceny snížené o 20%.

| b) | vlna v kusech | Kčs 164,— |
|---|---|---|
| c) | kousky (jakostní skupina I) | Kčs 110,— |
|  | Jakostní skupina II |  |
|  | třída II/3 | Kčs 130,— |
|  | třída II/4 | Kčs 110,— |
|  | kousky (jakostní skupina II) | Kčs 68,— |
|  | Jakostní skupina III |  |
|  | třída III/5 | Kčs 66,— |
|  | kousky (jakostní skupina III) | Kčs 30,— |

(2) K stanoveným cenám vyplatí výkupce chovateli ovcí zvláštní příplatek ve výši základní ceny za každý kilogram dodané vlny.

(3) Ceny se rozumějí za jeden kilogram čisté váhy prané vlny, bez všeobecné daně, franko výkupní místo.

**Body „OV“.**
