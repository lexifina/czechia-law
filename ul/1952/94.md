# Vyhláška státního úřadu plánovacího, kterou se vyhlašují za technické státní normy úsekové normy ministerstva potravinářského průmyslu pro některé potravinářské výrobky.

94\.

VYHLÁŠKA

státního úřadu plánovacího

ze dne 4. dubna 1952,

kterou se vyhlašují za technické státní normy úsekové normy ministerstva potravinářského průmyslu pro některé potravinářské výrobky.

Státní úřad plánovací vyhlašuje podle § 8 vládního nařízení č. 45/1951 Sb., o technické normalisaci:

### § 1.

Technickými státními normami jsou ode dne 24. dubna 1952 tyto normy:

|  |  | dříve úseková norma |
|---|---|---|
| ČSN 57 7111 | Safaládky (vuřty) | Ú 51 |
| ČSN 57 7126 | Párky | Ú 51 |
| ČSN 57 7128 | Debrecínské Párky | Ú 51 |
| ČSN 57 7141 | Moravské klobásy | Ú 51 |
| ČSN 57 7143 | Čabajská klobása | Ú 51 |
| ČSN 57 7156 | Jemné špekáčky | Ú 51 |
| ČSN 57 7211 | Kabanos | Ú 51 |
| ČSN 57 7213 | Obyčajná saláma konzumná | Ú 51 |
| ČSN 57 7215 | Pařížská saláma | Ú 51 |
| ČSN 57 7217 | Mortadella | Ú 51 |
| ČSN 57 7219 | Šunková saláma | Ú 51 |
| ČSN 57 7222 | Slovenská saláma | Ú 51 |
| ČSN 57 7223 | Prešovská saláma | Ú 51 |
| ČSN 57 7224 | Čabajská saláma | Ú 51 |
| ČSN 57 7264 | Trvanlivá saláma 80% | Ú 51 |
| ČSN 57 7412 | Jaterničky (biele) | Ú 51 |
| ČSN 57 7414 | Krvavníčky | Ú 51 |

### § 2.

Normy obsahují definice výrobků, pro které jsou vyhlášeny, údaje o znacích jakosti, o methodě kontroly jakosti, o hlavních znacích technologického postupu, o obalech, dopravě, skladování a jiné údaje, důležité pro jednotlivé výrobky.

### § 3.

Vyhlášené normy platí pro území Slovenska.

### § 4.

Normy uvedené v § 1 jsou uveřejněny ve sbírce „Soubor norem jakosti pro výrobky potravinářského průmyslu“, vydané Průmyslovým vydavatelstvím v Praze.

Za ministra-předsedu státního úřadu plánovacího:

Dr. Vlasák v. r.
