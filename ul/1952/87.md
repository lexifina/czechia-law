# Vyhláška státního úřadu plánovacího, kterou se vyhlašují technické státní normy pro slévárenské potřeby.

87\.

VYHLÁŠKA

státního úřadu plánovacího

ze dne 21. března 1952,

kterou se vyhlašují technické státní normy pro slévárenské potřeby.

Státní úřad plánovací vyhlašuje podle § 8 vládního nařízení č. 45/1951 Sb., o technické normalisaci:

### § 1.

Technickými státními normami jsou od 1. července 1952 normy:

| ČSN 04 2110 | „Podpěrky jader. Kruhové destičky“, |
|---|---|
| ČSN 04 2114 | „Podpěrky jader. Čtvercové a obdélníkové destičky“, |
| ČSN 04 2120 | „Podpěrky jader. Kruhové podpěrky“, |
| ČSN 04 2122 | „Podpěrky jader. Kruhové podpěrky se stopkou“, |
| ČSN 04 2124 | „Podpěrky jader. Čtvercové podpěrky“, |
| ČSN 04 2180 | „Podpěrky jader. Nesouměrné podpěrky“, |
| ČSN 04 2132 | „Podpěrky jader. Obdélníkové podpěrky“, |
| ČSN 04 2134 | „Podpěrky jader. Nesouměrné podpěrky 2/sloupkové“, |
| ČSN 04 2140 | „Podpěrky jader. Tyčkové podpěrky s rovnou destičkou“, |
| ČSN 04 2142 | „Podpěrky jader. Tyčkové podpěrky s ohnutou destičkou“, |
| ČSN 04 2144 | „Podpěrky radiátorových jader“, |
| ČSN 04 2146 | „Podpěrky jader. Spirálové podpěrky“, |
| ČSN 04 2148 | „Podpěrky jader. Praporkové podpěrky“, |
| ČSN 04 2150 | „Podpěrky jader. Rámkové podpěrky s patkou“, |
| ČSN 04 2152 | „Podpěrky jader. Rámkové podpěrky s patkou, ohnuté“, |
| ČSN 04 2154 | „Podpěrky jader. Rámkové podpěrky zástrčné“, |
| ČSN 04 2156 | „Podpěrky jader. Rámkové podpěrky zástrčné, ohnuté“, |
| ČSN 04 2163 | „Podpěrky jader. Pružné podpěrky“, |
| ČSN 04 2164 | „Jádrové podpěrky“. |

Tyto normy jsou směrné.

### § 2.

Normy obsahují údaje o rozměrech, váze, materiálu, o způsobu provedení a povrchové úpravě slévárenských potřeb.

Za ministra-předsedu státního úřadu plánovacího:

Dr. Vlasák v. r.
