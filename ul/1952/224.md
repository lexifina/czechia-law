# Vyhláška úřadu pro normalisaci, kterou se vyhlašují technické podmínky pro výrobky průmyslu těžkého strojírenství.

224\.

VYHLÁŠKA

úřadu pro normalisaci

ze dne 19. července 1952,

kterou se vyhlašují technické podmínky pro výrobky průmyslu těžkého strojírenství.
