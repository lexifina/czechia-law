# Vyhláška úřadu pro normalisaci, kterou se vyhlašují technické podmínky pro výrobky lehkého průmyslu, lesů a dřevařského průmyslu

227\.

VYHLÁŠKA

úřadu pro normalisaci

ze dne 26. července 1952,

kterou se vyhlášují technické podmínky pro výrobky lehkého průmyslu, lesů a dřevařského průmyslu

Úřad pro normalisaci vyhlašuje podle § 11 vládního nařízení č. 45/1951 Sb., o technické normalisaci:

### § 1.

Dokud nebudou vydány technické normy, stanoví se tyto technické podmínky:

Pro úsek lehkého průmyslu (pokračování k vyhlášce z 19. července 1952):

|  |  | s účinností od |
|---|---|---|
| TP 6-13-52 | Podkladové filtrační plachetky kalelisové, papírové, PS 750 | 18. 7. 1952 |
| TP 6-14-52 | Filtrace (filtrační textilie) | 18. 7. 1952 |
| TP 6-58-52 | Kožené pásky pro přádelny | 19. 7. 1952 |
| TP 6-59-52 | Rounodělící řemínky | 19. 7. 1952 |
| TP 6-60-52 | Řemínky Cassablanka a Kluftinger | 19. 7. 1952 |
| TP 6-61-52 | Válečkové dutinky | 19. 7. 1952 |
| TP 6-62-62 | Manžety kožené | 19. 7. 1952 |
| TP 6-63-52 | Ochranné zástěry z usní | 19. 7. 1952 |

Pro úsek lesů a dřevařského průmyslu (pokračování k vyhlášce z 19. července 1952):

|  |  | s účinností od |
|---|---|---|
| TP 8-2-52 | Isolační dehtovaná celulosová lepenka nepískovaná C 500 | 26. 7. 1962 |
| TP 8-3-52 | Isolační dehtová celulosová lepenka nepískovaná C 333 | 26. 7. 1962 |
| TP 8-4-52 | Isolační impregnovaná skelná tkanina | 26. 7. 1952 |
| TP 8-5-52 | Asfaltovaný papír | 26. 7. 1952 |
| TP 8-6-52 | Střešní dehtovaná celulosová lepenka pískovaná C 333 | 26. 7. 1952 |
| TP 8-7-52 | Střešní dehtovaná celulosová lepenka pískovaná C 500 | 26. 7. 1952 |

### § 2.

Technické podmínky uvedené v § 1 jsou závazné; vyhlášených podmínek je povinen dbát každý, jehož se týkají.
