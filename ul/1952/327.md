# Vyhláška státního úřadu plánovacího, kterou se vyhlašují technické státní normy pro odtlačovací šrouby s čípkem, pro zabezpečovací zařízení pro ústřední vytápění a pro ohřívání užitkové vody a pro zkoušení kovů.

327\.

VYHLÁŠKA

státního úřadu plánovacího

ze dne 24. září 1952,

kterou se vyhlašují technické státní normy pro odtlačovací šrouby s čípkem, pro zabezpečovací zařízení pro ústřední vytápění a pro ohřívání užitkové vody a pro zkoušení kovů.

Státní úřad plánovací vyhlašuje podle § 8 vládního nařízení č. 45/1951 Sb., o technické normalisaci:

### § 1.

(1) Technickými státními normami od 1. ledna 1958 jsou normy:

| ČSN 02 1115 | Odtlačovací šrouby s čípkem |
|---|---|
| ČSN 02 1116 | Odtlačovací šrouby s hrotem |
| ČSN 02 1121 | Upínací šrouby s osazeným koncem |
| ČSN 02 1122 | Upínací šrouby s nákružkem a s čípkem |
| ČSN 02 1134 | Šrouby s válcovou hlavou středního provedení |
| ČSN 02 1149 | Šrouby s půlkulovou hlavou středního provedení |
| ČSN 02 1154 | Zápustné šrouby středního provedení |
| ČSN 02 1158 | Zápustné šrouby s hlavou čočkovitou středního provedení |
| ČSN 02 1183 | Stavěcí šrouby se zářezem a s čípkem |
| ČSN 02 1185 | Stavěcí šrouby se zářezem a s hrotem |
| ČSN 02 1189 | Stavěcí šrouby s vnitřním šestihranem a s čípkem |
| ČSN 02 1191 | Stavěcí šrouby s vnitřním šestihranem a s hrotem; |

tyto normy jsou směrné.

(2) Normy pojednávají mimo jiné o rozměrech materiálu, provedení a pod. jednotlivých druhů šroubů, jichž se týkají.

### § 2.

(1) Technickou státní normou od 1. prosince 1952 je norma:

ČSN 06 0830 „Zabezpečovací zařízení pro ústřední vytápění a pro ohřívání užitkové vody“.

(2) Norma jedná o zabezpečovacích zařízeních nízkotlakových parních kotlů, teplovodních (otevřených) vytápěcích soustav, horkovodných (uzavřených) soustav a o zabezpečovacím zařízení ohříváků užitkové vody.

### § 3.

(1) Technickými státními normami od 1. ledna 1953 jsou normy:

| ČSN 42 0304 | Braní a zpracování zkušebních vzorků |
|---|---|
| ČSN 42 0310 | Zkouška tahem |
| ČSN 42 0311 | Zkušební tyče pro zkoušky tahem |
| ČSN 42 0314 | Zkušební tyče kruhové k upínání kroužky pro zkoušky tahem |
| ČSN 42 0315 | Zkušební tyče kruhové s hladkými válcovými hlavami pro zkoušky tahem |
| ČSN 42 0316 | Zkušební tyče kruhové se závitovými hlavami pro zkoušky tahem |
| ČSN 42 0317 | Zkušební tyče kruhové s osazenými hlavami pro zkoušky tahem |
| ČSN 42 0371 | Zkouška tvrdosti podle Brinella |
| ČSN 42 0373 | Zkouška tvrdosti podle Rockwella |
| ČSN 42 0374 | Zkouška tvrdosti podle Vickerse |
| ČSN 42 0381 | Zkouška vrubová rázem |

(2) Norma ČSN 42 0304 pojednává mimo jiné všeobecně o braní a zpracování zkušebních vzorků. Ostatní normy uvedené v § 1 jednají o jednotlivých druzích mechanických zkoušek a zkušebních prostředcích.

Za ministra-předsedu státního úřadu plánovacího:

Dr. Vlasák v. r.
