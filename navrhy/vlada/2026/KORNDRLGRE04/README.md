# Vyhláška, kterou se mění vyhláška č. 242/2025 Sb., o dispečerském řízení elektrizační soustavy (dispečerská vyhláška)

**Description:** Doplnění úpravy semaforu o oranžovou a šedou barvu

**Reason:** Návrh vyhlášky je předkládán s cílem doplnit do právní úpravy tzv. semaforu jeho další funkcionality tak, aby byl zajištěn rychlejší přístup pro nově připojovaná zařízení na trh s flexibilitou. Navrhovaná úprava doplňuje stávající dispečerskou vyhlášku, která provádí novelu energetického zákona, tzv. LEX OZE III.
