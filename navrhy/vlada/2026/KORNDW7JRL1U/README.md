# Návrh zákona, kterým se mění některé zákony s cílem posílit odolnost subjektů kritické infrastruktury proti bezpilotním systémům

**Description:** Změna zákonů o civilním letectví a o Policii České republiky připravená v rámci výboru Bezpečnostní rady státu pro protidronovou ochranu, dronovou regulaci a rozvoj, jejímž cílem je posílit odolnost subjektů kritické infrastruktury proti bezpilotním systémům.

**Reason:** Návrh se předkládá nad rámec úkolů uložených Plánem legislativních prací vlády na zbývající část roku 2026 na základě aktuální potřeby posílit odolnost kritické infrastruktury proti útokům bezpilotních letadel.
