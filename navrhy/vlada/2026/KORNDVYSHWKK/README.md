# Nařízení vlády o standardech pro akreditace ve vysokém školství

- Type: Návrh nařízení vlády
- Submitted by: Vláda České republiky
- Status: 6 - přijato ÚV ke zpracování
- PID: KORNDVYSHWKK

**Description:** Naplňuje se nové zmocnění pro vydání nařízení vlády obsažené v § 82a zákona č. 111/1998 Sb. Zajišťuje se soulad příslušných standardů se standardy a směrnicemi pro zajištění kvality v Evropském prostoru vysokoškolského vzdělávání.

**Reason:** Návrh nařízení vlády (zpracovaný nad rámec úkolů uložených Plánem legislativních prací vlády na zbývající část roku 2026) reaguje na podnět Národního akreditačního úřadu pro terciární vzdělávání.
