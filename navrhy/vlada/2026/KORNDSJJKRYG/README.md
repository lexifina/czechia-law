# Návrh zákona o platformové práci

Material of the government's legislative system (eKLEP/VeKLEP, ODok), <https://odok.gov.cz/portal/veklep/material/KORNDSJJKRYG/>.

- Type: Návrh zákona
- Submitted by: Ministerstvo práce a sociálních věcí
- Status: B - signováno
- PID: KORNDSJJKRYG
- Číslo jednací (OVA): 563/26
- Reference of the submitter: MPSV-2025/213059-521
- Authorised for comment: 2026-03-26
- Comments due: 2026-04-27
- Government meeting: 2026-08-31
- Keywords: bezpečnost a ochrana zdraví při práci, organizace práce a pracovní podmínky, pracovně-právní vztahy, zaměstnanost

**Description:** Cílem návrhu zákona je transponovat směrnici Evropského parlamentu a Rady (EU) 2024/2831 ze dne 23. října 2024 o zlepšení pracovních podmínek při práci prostřednictvím platformy (dále jen „Směrnice“). Účelem Směrnice je zlepšit pracovní podmínky zaměstnanců digitálních pracovních platforem a také ochrana osobních údajů při platformové práci pro všechny platformové pracovníky (tedy jak pro zaměstnance, tak další osoby – zejm. OSVČ). 

Součástí návrhu zákona je nový zákon o platformové práci a dále novely souvisejících právních předpisů, a to zákoníku práce, zákona o zaměstnanosti, občanského soudního řádu, zákona o pobytu cizinců na území České republiky, zákona o inspekci práce, zákona o ochraně oznamovatelů a zákona o jednotném měsíčním hlášení zaměstnavatele.

**Reason:** Transpozice směrnice Evropského parlamentu a Rady (EU) 2024/2831 ze dne 23. října 2024 o zlepšení pracovních podmínek při práci prostřednictvím platformy, jejíž transpoziční lhůta uplyne 2. prosince 2026.
