# Cenové rozhodnutí Energetického regulačního úřadu č. 3/2014 ze dne 25. listopadu 2014, kterým se stanovují regulované ceny související s dodávkou elektřiny odběratelům ze sítí nízkého napětí, se zrušuje. VII. Účinnost Cenové rozhodnutí nabývá účinnosti dnem 1. ledna 2016. Předsedkyně Energetického regulačního úřadu

Cenové rozhodnutí Energetického regulačního úřadu č. 3/2014 ze dne 25. listopadu 2014, kterým se stanovují regulované ceny související s dodávkou elektřiny odběratelům ze sítí nízkého napětí, se zrušuje.
VII. Účinnost
Cenové rozhodnutí nabývá účinnosti dnem 1. ledna 2016.
