# Cenové rozhodnutí Energetického regulačního úřadu č. 6/2011 ze dne 21. listopadu 2011, kterým se stanovují ceny regulovaných služeb souvisejících s dodávkou elektřiny odběratelům ze sítí nízkého napětí, se zrušuje. VII. Účinnost Cenové rozhodnutí nabývá účinnosti dnem 1. ledna 2013. Předsedkyně Energetického regulačního úřadu

Cenové rozhodnutí Energetického regulačního úřadu č. 6/2011 ze dne 21. listopadu 2011, kterým se stanovují ceny regulovaných služeb souvisejících s dodávkou elektřiny odběratelům ze sítí nízkého napětí, se zrušuje.
