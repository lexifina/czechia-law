# Cenové rozhodnutí Energetického regulačního úřadu č. 4/2020 ze dne 4. června 2020, o regulovaných cenách souvisejících s dodávkou plynu, se zrušuje.

Cenové rozhodnutí Energetického regulačního úřadu č. 4/2020 ze dne 4. června 2020, o regulovaných cenách souvisejících s dodávkou plynu, se zrušuje.
(4) Účinnost
Cenové rozhodnutí nabývá účinnosti dnem 1. ledna 2022, s výjimkou bodu (2.2), který nabývá účinnosti dnem 4. června 2021.
